# Onroad 지구력코어 — 프리미엄 벤치마크 플레이북

> 동급 최고의 프리미엄 건기식·러너/스포츠·에디토리얼 커머스 사이트를 해부해, "무엇이 그들을 프리미엄으로 보이게 하는가"를 **구조·타이포·모션·여백·카피** 다섯 축으로 정리한다. 이 문서는 3개 아트디렉션 목업의 공통 북극성이다.

---

## 0. 한 문단 명제

프리미엄은 "더 많이"가 아니라 **"덜, 그러나 정확하게"**에서 온다. 싸구려 사이트는 색·그림자·둥근모서리·애니메이션·느낌표를 쌓아 주의를 구걸하고, 프리미엄 사이트는 **여백·위계·절제·일관성**으로 신뢰를 *가정*한다. 화면이 "팔려고 안달하지 않을수록" 비싸 보인다. 건기식에서는 여기에 하나가 더 붙는다 — **근거의 차분한 제시**(성분·함량·인정 클레임을 과장 없이). 러너 브랜드에서는 **정서와 데이터의 공존**(새벽의 감정 + 케이던스·페이스의 정밀). Onroad는 이 셋의 교집합에 선다.

---

## 1. 카테고리별 해부

### A. 프리미엄 건기식 — AG1 / Ritual / Momentous / LMNT / Seed / Heights
- **신뢰를 "디자인"한다**: 임상·성분·투명성을 *조용한* 데이터 레이아웃으로. Ritual은 "투명 캡슐"을 메타포 삼아 성분 출처를 한 줄씩 인덱싱한다. 약국처럼 보이지 않으면서 과학을 말한다.
- **단일 히어로 제품**: SKU를 늘어놓지 않고 한 제품을 영웅화. 함량 숫자(예: 40mg)를 타이포 오브제로 키운다.
- **루틴 서사**: "하루 한 번", "30일", "느껴지는 변화"를 *습관*의 언어로. 효능 단정 대신 꾸준함을 판다.
- **안티패턴**: 알약 클로즈업 스톡사진, 형광 그린, 별점 5개 배지 도배, "기적/완치" 류 카피.

### B. 러너 / 스포츠 — On Running / Tracksmith / Satisfy / Bandit / SOAR / District Vision / Nike Run
- **정서 ↔ 데이터의 진자운동**: Tracksmith는 보스턴 러닝 문화를 *문학*으로 쓰고(에디토리얼), On/Whoop은 같은 러닝을 *계기판*으로 쓴다(텔레메트리). 둘 다 프리미엄. 핵심은 한 쪽을 **확신을 갖고** 밀어붙이는 것.
- **아카이브·헤리티지 프레이밍**: "EST", "Vol.", 시즌·연감 넘버링이 신뢰의 시간성을 만든다.
- **러너 인사이더 언어**: 케이던스, 스플릿, 30km의 벽, PB, sub-3 — 아는 사람에게 말하는 정밀함이 동경을 만든다.
- **루트/모션 메타포**: GPS 트랙 라인, 등고선, 페이스 그래프를 그래픽 장치로.
- **안티패턴**: 과장된 "에너지 폭발" 비주얼, 의미 없는 스피드 라인, 모델 미소 스톡.

### C. 에디토리얼 / 럭셔리 미니멀 — Aesop / Le Labo / Byredo / Aimé Leon Dore / COS / Kinfolk / Cereal / Hermès
- **타이포가 곧 브랜드**: 한 벌의 활자(여기선 Noto Serif/Sans/Mono)를 weight·size·italic만으로 운용. 장식 폰트 0개.
- **극단적 여백 = 자신감**: 콘텐츠 사이 12–18vw의 침묵. 화면을 채우지 않는 것이 럭셔리.
- **모션의 절제**: 등장은 250–600ms 페이드/슬라이드, easing은 ease-out 계열. 바운스·회전·패럴랙스 남발 금지.
- **카피의 큐레이션**: 적은 단어, 큰 무게. 마침표가 있는 짧은 선언문.
- **안티패턴**: 그라디언트 버튼, 다중 드롭섀도, 둥근 모서리 카드, 자동재생 캐러셀.

## 2. 다섯 축 — 처방전(Prescriptive Checklist)

### 구조 (Structure)
- 한 화면 = 하나의 생각. 섹션마다 단 하나의 메시지·하나의 CTA.
- 비대칭 에디토리얼 그리드(예: 4:8, 5:7 분할) + 헤어라인 룰로 "지면"을 만든다.
- 챕터·폴리오 넘버링([01]·№ 01·Vol.01)으로 읽기의 시간성을 부여.
- 히어로 → 근거(성분/데이터) → 정서(러너) → 제품 상세 → 최종 CTA 의 리듬.

### 타이포 (Typography)
- 디스플레이는 **serif weight 300 + 음수 자간**(한글은 Noto Serif KR 명조) — 속삭이는 권위.
- 강조는 **serif italic**, 시그널 레드는 한 화면에 1단어 내외.
- 데이터·eyebrow·캡션은 **mono UPPERCASE, 자간 0.12–0.2em**, 숫자는 tabular-nums.
- 위계는 크기보다 **대비**(300 vs 700, serif vs mono)로. 3단계 위계면 충분.
- 본문 max-width 42–48ch, line-height 1.6–1.7.

### 모션 (Motion)
- 등장: opacity+translateY(8–16px), 250–600ms, ease-out. 한 번만(once).
- 스크롤 매개: 이미지 1.0→1.1 스케일, 헤더 상태 전환 같은 *미세한* 것만.
- 시그널 모션은 의미 있는 곳에만(라이브 도트 펄스, 카운터, 루트 드로우).
- **금지**: 바운스, 무한 회전, 자동 캐러셀, 패럴랙스 과용, 등장 지연으로 인한 빈 화면.

### 여백 (Whitespace)
- 섹션 패딩 clamp(72px, 9vw, 140px). 침묵을 두려워하지 않는다.
- 8px 베이스 스페이싱 스케일을 엄격히. 임의 값 금지.
- 텍스트 블록 주변에 "방"을 준다 — 캡션/마지널리아가 여백 속에 떠 있게.

### 카피 (Copy)
- 한국어 에디토리얼 + 영문 mono 라벨의 이중 레이어.
- 짧은 선언문 + 마침표. "더 멀리, 더 오래." 류.
- 효능 단정 금지 → "지구력 증진에 **도움을 줄 수 있음**". 면책 문구 상시.
- 숫자는 카피다: 40mg / 1정 / 60일 / 178 cadence.

## 3. 안티패턴 (싸구려로 보이게 만드는 것들)
1. 둥근 모서리 + 드롭섀도 카드 더미 2. 그라디언트/네온 버튼 3. 스톡 알약·웃는 모델 사진 4. 별점 배지·"베스트셀러" 스티커 도배 5. 자동재생 캐러셀·팝업 6. 폰트 3종 이상 혼용 7. 꽉 찬 화면(여백 공포) 8. 무의미한 모션 9. 느낌표·전부 대문자 강매 카피 10. 효능 과장.

---

## 4. The 10 Moves — Onroad가 둘 중 할 일

1. **단일 히어로 제품 영웅화**: 옥타코사놀 40mg을 타이포 오브제로. SKU 나열 금지.
2. **명조 디스플레이를 시그니처로**: 큼직한 Noto Serif KR 300 + 한 단어 레드 이탤릭.
3. **숫자를 타이포로**: 40 / 1 / 60 / 178을 mono tabular로 크게, 캡션으로 의미 부여.
4. **헤어라인 룰로 지면 만들기**: 1px var(--c-line)로 섹션을 인쇄물처럼 구획.
5. **챕터/폴리오 넘버링**: [01]–[05], № 01, Vol.01 / 2026 으로 시간성·아카이브감.
6. **러너 인사이더 언어**: 30km의 벽·페이스·케이던스·sub-3 로 동경 유발.
7. **시그널 레드는 한 방울**: 한 화면 1회. 잉크 한 점처럼.
8. **모션은 절제·의미 있게**: 페이드·헤어라인 드로우·카운터·루트 라인만. 등장은 항상 visible로 settle.
9. **근거의 차분한 제시**: 성분·함량·인정 클레임·면책을 데이터 리스트로 조용히.
10. **여백으로 비싸 보이기**: 섹션 사이 침묵, 텍스트 주변 "방", 화면을 채우지 않기.

---

## 5. 세 아트디렉션으로의 번역

같은 정수(장거리 러너·옥타코사놀 40mg·따뜻한 페이퍼+시그널 레드·에디토리얼)를 **세 렌즈**로:

- **A. THE FIELD JOURNAL** — 위 원칙을 *인쇄물*의 렌즈로. 여백·명조·폴리오·마지널리아 극대화. 가장 "조용한 럭셔리".
- **B. PACE / TELEMETRY** — *계기판*의 렌즈로. mono 데이터·그리드·루트·게이지·라이브 레드. 가장 "정밀·기술".
- **C. THE LONG ROAD** — *시네마*의 렌즈로. 새벽 도로·풀블리드 분위기·고요한 큰 타이포. 가장 "정서·동경".

세 안 모두 §2의 처방전과 §4의 10 Moves를 지키되, **확신의 방향**만 다르다 — 그것이 프리미엄의 조건이다.
