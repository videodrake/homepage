## 고유 앵글

**도입**: 자기소개로 시작하지 말고 "고민"이나 "회의"부터 던진다. 예:
- "후반부가 매번 무너지는 게 몇 년째 고민이었어요."
- "보충제 이것저것 돌려 먹어봤는데 솔직히 다 비슷했거든요."
- "이번에도 반신반의로 시작했습니다."

**흐름**: 회의적 시작 → 섭취 기간 언급 → 관찰된 (은은한) 변화 1~2개 → 여지 + 긍정 행동으로 마무리.

**주의**: "플라시보일 수도 있지만" 표현은 **이 리뷰에서 안 써도 됨**. 쓰더라도 다른 헤지 표현(_shared.md 참고)을 섞어 다양화.

**분량**: 한국어 **180~300자**, 2~4문장.

### 예시 (참고만, 구조 복제 금지)

> 후반부가 매번 무너지는 게 몇 년째 고민이었어요. 이번에도 반신반의로 한 통 시작했는데 30일 넘기고 보니까 같은 코스 LSD에서 페이스 유지가 조금 수월한 날이 늘었어요. 기분탓일 수도 있는데 며칠 반복되니까 우연은 아닌 것 같고, 일단 한 통 더 시켰습니다.

> BCAA랑 비타민 돌려 먹던 시절엔 사실 뭘 먹어도 별 차이를 못 느껴서 그만뒀었는데 이건 3주 지나고 나니까 인터벌 다음날이 예전이랑 좀 다릅니다. 숫자로 딱 집긴 어려운데 회복런 나갈 때 다리가 덜 뻣뻣하달까요. 대회 전까지는 유지해보려고요.
