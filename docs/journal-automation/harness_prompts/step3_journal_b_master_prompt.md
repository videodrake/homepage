# Step 3 하네스 프롬프트 - Journal B 마스터 작성

아래 입력값과 Journal A 요약을 바탕으로 `Journal №X-B` 자사몰 마스터 글 1편을 작성하라.  
Journal B는 A에서 연 정보갭을 닫는 실천 편이다. 결과물은 자리 2(Codex)의 파서와 이미지 생성 파이프라인에 바로 넘길 수 있는 `.md` 파일이어야 한다.

사용자가 검토한 최종 파일은 `content/draft/journal-01-b.md`에 저장된다. 이후 Codex가 `codex/journal-01-b` 브랜치와 `journal-ready` 라벨 PR로 처리하고, Claude Code 자리 3이 homepage 배포를 이어받는다.

## 입력값

```yaml
series_no: "01"
part: "B"
series_title: "30km 페이스 유지"
journal_title: "30km 이후 페이스를 지키는 법"
slug: "journal-01-b"
active_series_id: "journal-01"
split_pattern: "진단/실천 중 실천"
target_reader: "30km 이후 페이스 저하의 원인을 이해했고, 훈련과 레이스 운영 방법을 알고 싶은 러너"
core_question: "30km 이후 페이스 저하를 줄이려면 훈련과 레이스 당일 운영에서 무엇을 바꿔야 하는가?"
one_message: "후반 페이스는 지방 산화 능력을 키우는 훈련과 레이스 중 탄수화물 공급 계획이 함께 맞물릴 때 안정된다."
must_answer_from_journal_a:
  - "Journal A는 30km 이후 문제가 글리코겐 한계와 지방 동원 속도 차이에서 시작된다고 설명했다."
  - "Journal B는 그 문제를 줄이는 훈련 방향과 레이스 당일 계산법을 제시한다."
h2_plan:
  - "지방을 더 잘 태우는 몸 만들기"
  - "레이스 당일 탄수화물 시간당 g 계산"
naver_cluster_mapping:
  - h2: 1
    working_title: "존2 트레이닝이 마라톤 후반 페이스에 미치는 영향"
    keyword: "존2 트레이닝, 지방 산화"
  - h2: 2
    working_title: "마라톤 당일 탄수화물 섭취, 시간당 몇 g이 적정한가"
    keyword: "마라톤 탄수화물, 레이스 영양"
required_sources:
  - "사용 가능한 Project Knowledge의 연구/룰북 문서"
  - "수치와 권고는 개인차가 있음을 명시하고 단정적 지시로 쓰지 말 것"
```

## 반드시 참조할 Project Knowledge

- `운영_룰북/mode_journal.md`
- `운영_룰북/이미지_가이드.md`
- `운영_룰북/발행_매핑_가이드.md`
- `운영_룰북/규제_핵심요약_치트시트.md`
- `자리1_출력사양.md`
- `자리1_자가검증.md`
- `자리1_활성시리즈.md`
- `자리1_콘텐츠품질_가이드.md`

## 작업 순서

1. 입력값을 6줄 이내의 `설계 메모`로 압축한다.
2. Journal A의 진단을 2~3문장으로만 회수하고, 본문 대부분은 실천에 쓴다.
3. H2는 정확히 2개만 쓴다.
4. H2-1은 훈련 방향, H2-2는 레이스 당일 계산과 운영으로 역할을 분리한다.
5. 개인별 지시처럼 보이는 표현을 피하고, 일반 훈련 정보로 쓴다.
6. 본문 중간에 이미지 마커 5~8개를 배치한다.
7. 글 끝에 `## 이미지 명세` 섹션을 만들고 모든 마커와 1:1로 맞춘다.
8. 마지막에 `## 검증 리포트`를 붙인다.
9. Codex 전달 위치가 `content/draft/journal-01-b.md`임을 검증 리포트에 포함한다.
10. 첫 300~500자는 실천법 요약이 아니라 실제 러너가 대회 전후에 겪는 장면으로 시작한다.
11. SEO/AEO를 위해 핵심 요약, H2, FAQ는 검색 의도에 답하는 구조로 쓴다.
12. AI처럼 지나치게 균일한 문체를 피하고, 과학 기반 설명이 러너의 일상 문제 해결로 이어지게 쓴다.
13. 각 H2 첫 문단은 그 섹션의 결론을 먼저 말한다.
14. 출처 없는 "연구에 따르면" 표현을 쓰지 않는다.
15. 한국 30~40대 러너가 바로 알아볼 생활/대회 맥락을 최소 2개 넣는다. 예: 새벽 대회장, 물품보관소, 화장실 줄, 출발 그룹 대기, 한강/잠실/여의도/상암/광화문 러닝 장면, 러닝크루 단체 채팅방, Garmin/Strava 기록 확인, 카카오톡 기록 캡처 공유.
16. 독자를 탓하거나 혼내지 않는다. "의지가 약해서"가 아니라 "몸 안의 계산이 달라지는 구간"으로 설명한다.
17. 과한 응원, 썸네일식 과장, 친한 척하는 구어체를 피한다. "할 수 있습니다", "꿀팁", "아직도 이렇게 뛰나요?" 같은 표현보다 차분한 경어체와 짧은 체언 종결을 섞는다.
18. 최종 출력 전 유용성, 신뢰, 웹 독해, 한국 독자 감성, AI스러움 제거 순서로 5회 편집한다.

## 실패 조건

아래 중 하나라도 발생하면 최종 출력 전에 스스로 수정하라.

- Journal A 내용을 길게 반복한다.
- H2-1과 H2-2가 모두 훈련 이야기이거나 모두 레이스 당일 이야기다.
- 개인에게 특정 섭취량을 지시하듯 단정한다.
- 이미지 마커가 `[IMG-N: 식별명]` 단독 줄이 아니다.
- 마커 식별명과 명세 식별명이 글자 단위로 다르다.
- 제품명, 성분명, 5대 금지어, 의약품 오인 용어가 나온다.
