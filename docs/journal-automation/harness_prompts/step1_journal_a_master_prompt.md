# Step 1 Harness Prompt - Journal 01-A First Article

이 프롬프트는 Claude Project에서 첫 자사몰 Journal 글 `journal-01-a.md`를 만들 때 그대로 붙여넣는 실행용이다.

목표는 글쓰기 품질뿐 아니라 자리 2(Codex)와 자리 3(Claude Code)이 바로 처리할 수 있는 **기계 호환 마크다운**을 만드는 것이다.

품질 목표는 다음이다.

- 블로그 글로서 첫 문단에서 관심을 만든다.
- SEO/AEO 최적화를 통해 검색 유입 가능성을 높이되, Google AI Search 대응을 별도 해킹이 아니라 사람 중심 SEO로 다룬다.
- 흔한 AI 요약이나 목록형 팁이 아니라 한국 러너 맥락, 숫자, 조건, 한계를 담은 비상품성 콘텐츠로 만든다.
- 실제 러너들이 겪는 일상 문제와 장면을 반영한다.
- AI가 쓴 것처럼 지나치게 완벽하고 매끈한 문체를 피한다.
- 과학적 기반을 갖추되, 독자의 문제 해결로 이어지게 쓴다.
- AI가 설명하기 어렵거나 검증하기 어려운 주제는 피한다.

## Writing Rules

1. Journal 톤으로 쓴다. 검색용 블로그가 아니라 자사몰 매거진 자산이다.
2. H2는 정확히 2개만 쓴다.
3. H2-1과 H2-2는 각각 나중에 네이버 TOFU 클러스터 1편으로 분리될 수 있어야 한다.
4. 본문에는 제품명과 성분명을 쓰지 않는다.
5. 5대 금지어와 의약품 오인 용어를 쓰지 않는다.
6. 푸터, 하단 버튼, 제품 페이지, 구매 안내를 암시하지 않는다.
7. 본문 끝에는 면책 문구를 넣는다.
8. 이미지 마커는 5~8개를 본문 중간에 배치한다.
9. 이미지 명세는 모든 마커와 1:1로 맞춘다.
10. 이미지 프롬프트에는 각 이미지의 고유 내용만 쓴다. 시리즈 공통 색감, 모델, 조명, 스타일은 자리 2가 자동 주입하므로 반복하지 않는다.

## Quality Rules

1. 첫 300~500자는 정의나 설명이 아니라 장면으로 시작한다.
2. 도입부에는 실제 러너가 알아볼 만한 순간을 넣는다. 예: 30km 표지판, 랩 페이스 확인, 보급소를 지난 뒤의 계산, 다리가 먼저 둔해지는 느낌.
3. 실제 인터뷰를 한 것처럼 쓰지 않는다. 러너의 흔한 경험은 합성 장면으로만 쓴다.
4. 제목, 핵심 요약, H2, FAQ에는 검색 의도를 자연스럽게 반영한다. 키워드를 반복하지 않는다.
5. 핵심 요약은 AEO 답변형으로 쓴다. 첫 문장에서 질문에 직접 답한다.
6. FAQ는 3~5개로 작성하고, 각 답변 첫 문장에서 결론을 먼저 말한다.
7. 검색어 변형별 중복 글, llms.txt, AI 전용 요약, 본문에 없는 FAQ/구조화 데이터는 만들지 않는다.
8. 비교표 또는 숫자 요약을 1개 이상 넣는다.
9. 과학 설명은 `러너의 문제 -> 몸 안의 원리 -> 숫자/비교 -> 적용 -> 한계` 순서로 연결한다.
10. 문장 길이를 일부러 모두 같게 맞추지 않는다. 짧은 문장, 중간 길이 문장, 한 문장짜리 문단을 섞는다.
11. "중요한 것은", "결론적으로", "핵심은" 같은 AI식 연결어 반복을 피한다.
12. 검증하기 어려운 논문명, 질환, 통증 진단, 개인별 처방, 특정 성분 중심 설명은 쓰지 않는다.
13. 독자가 읽고 나서 다음 훈련이나 대회 준비에서 무엇을 관찰해야 하는지 알 수 있어야 한다.
14. 각 H2의 첫 문단은 그 섹션의 결론을 먼저 말한다.
15. 긴 문단은 3~5문장 안에서 끊고, 비교표나 짧은 목록으로 스캔 가능한 지점을 만든다.
16. "연구에 따르면"처럼 출처 없는 권위 표현을 쓰지 않는다. 출처를 정확히 모르면 일반 원리로 낮춰 쓴다.
17. 한국 30~40대 남성 러너가 바로 알아볼 생활/대회 맥락을 최소 2개 넣는다. 예: 새벽 대회장, 물품보관소, 화장실 줄, 출발 그룹 대기, 한강/잠실/여의도/상암/광화문 러닝 장면, 러닝크루 단체 채팅방, Garmin/Strava 기록 확인, 카카오톡 기록 캡처 공유.
18. 독자를 탓하거나 혼내지 않는다. "의지가 약해서"가 아니라 "몸 안의 계산이 달라지는 구간"으로 설명한다.
19. 과한 응원, 썸네일식 과장, 친한 척하는 구어체를 피한다. "할 수 있습니다", "꿀팁", "아직도 이렇게 뛰나요?"보다 차분한 경어체와 짧은 체언 종결을 섞는다.

## Image Marker Rules

```text

```


마커의 식별명과 명세의 식별명은 글자 단위로 같아야 한다.

## Self-Repair Before Final Output

최종 출력 전에 스스로 아래를 확인하고, 하나라도 틀리면 출력 전에 수정한다.

- H2가 3개 이상이면 2개로 줄인다.
- `[IMG_1]`, `[img-1]`, `[IMG1]`, `[이미지 1]` 같은 변형 마커가 있으면 표준 형식으로 고친다.
- `## 이미지 명세`가 없으면 추가한다.
- 명세가 마커보다 적거나 많으면 1:1로 맞춘다.
- 이미지 프롬프트에 시리즈 공통 톤 키워드를 반복했으면 제거한다.
- 금지어가 있으면 다른 일반 건강정보 표현으로 바꾼다.
- 도입부가 설명문처럼 시작하면 실제 러너 장면으로 다시 쓴다.
- 문장이 너무 반듯하고 균일하면 문단 길이와 연결어를 조정한다.
- 검색 키워드가 반복되면 검색 의도는 유지하고 반복어를 줄인다.
- 최종 출력 전 `유용성 -> 신뢰 -> 웹 독해 -> 한국 독자 감성 -> AI스러움 제거` 순서로 5회 편집한다.
