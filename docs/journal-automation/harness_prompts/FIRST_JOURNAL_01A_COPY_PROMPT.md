## Claude Project에 붙여넣을 지시문

```text
Project Knowledge의 다음 문서를 적용해서 Journal 01-A를 작성해줘.

- 운영_룰북/mode_journal.md
- 운영_룰북/이미지_가이드.md
- 운영_룰북/발행_매핑_가이드.md
- 운영_룰북/규제_핵심요약_치트시트.md
- 자리1_출력사양.md
- 자리1_자가검증.md
- 자리1_활성시리즈.md
- 자리1_콘텐츠품질_가이드.md

목표 파일:
- filename: journal-01-a.md
- slug: journal-01-a
- series_id: journal-01
- title: 왜 30km에서 무너지는가

핵심 질문:
왜 30km 이후 같은 페이스가 갑자기 어려워지는가?

한 줄 메시지:
30km 이후의 페이스 저하는 의지 문제가 아니라 제한된 글리코겐과 지방 동원 속도의 차이에서 시작된다.

H2는 정확히 2개:
1. 글리코겐 2,000kcal와 마라톤 2,800kcal
2. 남은 30%에서 갈리는 두 부류

네이버 클러스터 씨앗:
1. 마라톤 30km에서 다리가 멈추는 이유 - 800kcal 부족분 계산 / 마라톤 30km 벽, 글리코겐 고갈
2. 글리코겐과 지방, 러너 몸은 둘을 어떻게 나눠 쓰나 / 글리코겐 vs 지방, 에너지 시스템

출력 조건:
- 하나의 마크다운 파일 내용만 출력
- 코드블록으로 감싸지 말 것
- frontmatter 포함
- 작성 전 내부적으로 reader_problem, search_intent, answer_first, runner_scene, korean_context, science_basis, daily_application, risk_boundary, original_angle을 정리하되 출력하지 말 것
- 첫 300~500자는 설명이 아니라 실제 러너가 알아볼 장면으로 시작
- SEO/AEO를 위해 핵심 요약 첫 문장에서 질문에 직접 답변
- H2와 FAQ는 검색자가 실제로 묻는 문제 문장에 가깝게 작성
- 각 H2 첫 문단은 그 섹션의 결론을 먼저 말할 것
- FAQ 3~5개, 각 답변 첫 문장에 결론 우선
- 실제 러너의 흔한 상황을 최소 2개 반영하되 인터뷰/취재처럼 꾸미지 말 것
- 한국 30~40대 남성 러너가 바로 알아볼 생활/대회 맥락을 최소 2개 넣을 것. 예: 새벽 대회장, 물품보관소, 화장실 줄, 출발 그룹 대기, 한강/잠실/여의도/상암/광화문 러닝 장면, 러닝크루 단체 채팅방, Garmin/Strava 기록 확인, 카카오톡 기록 캡처 공유
- 독자를 탓하거나 혼내지 말 것. "의지가 약해서"가 아니라 "몸 안의 계산이 달라지는 구간"으로 설명할 것
- "할 수 있습니다", "꿀팁", "아직도 이렇게 뛰나요?" 같은 과한 응원/썸네일식 과장/친한 척하는 구어체를 피하고, 차분한 경어체와 짧은 체언 종결을 섞을 것
- 과학 설명은 러너의 문제 -> 몸 안의 원리 -> 숫자/비교 -> 적용 -> 한계 순서
- AI가 쓴 것처럼 모든 문단이 지나치게 반듯하거나 균일하지 않게 작성
- 검증하기 어려운 논문명, 질환, 통증 진단, 개인별 처방 주제는 피할 것
- 출처 없는 "연구에 따르면" 표현을 쓰지 말 것
- 긴 문단은 3~5문장 안에서 끊고, 표나 짧은 목록으로 스캔 가능한 지점을 만들 것
- 이미지 마커 5~8개
- 모든 이미지 마커는 [IMG-N: 식별명] 단독 줄
- ## 이미지 명세 포함
- 모든 명세 헤더는 ### IMG-N — 식별명
- 각 명세에는 종류, 비율, alt 텍스트, 프롬프트 필수
- 제품명 0회
- 성분명 0회
- 5대 금지어 0회
- 의약품 오인 용어 0회
- 푸터/하단/제품 페이지/구매 안내 0회
- 본문 끝에 일반 건강정보 면책 문구 포함
- 마지막에 검증 리포트 요약 포함
- 검증 리포트에는 `[IMG-1]`, `[IMG-1: ...]` 같은 이미지 마커 문자열을 반복하지 말 것
- 사용자가 저장할 원고 본문은 반드시 YAML frontmatter `---`부터 시작하게 할 것
- 선정 이유와 인계 메모는 원고 안에 섞지 말고, 원고 앞 3줄 이내 안내문으로만 분리할 것
- 검증 리포트에는 파일명, slug, H2 2개, 이미지 마커 5~8개, 마커-명세 1:1, 필수 이미지 필드, 제품명 0회, 성분명 0회, 5대 금지어 0회, 의약품 오인 용어 0회, 푸터/하단/제품 페이지/구매 안내 0회, 면책 문구, 첫 300~500자 장면, 핵심 요약 직접 답변, FAQ 3~5개, 한국 생활/대회 맥락 최소 2개, 독자를 탓하거나 혼내는 말투 없음, 과학 설명 순서, 출처 없는 "연구에 따르면" 없음, 긴 문단 없음 항목을 포함할 것

중요:
이미지 프롬프트에는 각 장면의 고유 내용만 적고, 시리즈 공통 색감/모델/조명/스타일은 반복하지 마. 그 부분은 Codex 자리 2가 series_blocks/journal-01.yaml에서 자동 주입한다.
```
