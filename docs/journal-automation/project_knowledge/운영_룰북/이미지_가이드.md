# 이미지 가이드

> 콘텐츠 작성 시 본문에 이미지 마커를 두고, 글 끝 "이미지 명세" 섹션에 GPT Image 2 프롬프트를 모아두는 방식.
> 이미지 생성 도구: **GPT Image 2 (GPT-4o Image Generation)** — 자연어 서술 정확, 텍스트 렌더링 가능, 데이터 시각화 처리 가능.
> 모든 이미지는 AI로 생성한다는 전제로 작성되었다.
> v3 (2026-04-28). 마커+명세 섹션 분리 방식으로 전환.

---

## 1. 왜 이미지가 중요한가

타겟(30~40대 한국 남성 러너)은 모바일에서 콘텐츠를 소비한다. 네이버 모바일 트래픽 70% 이상, 인스타그램은 100% 모바일이다. 모바일 환경에서 사람은 **글보다 이미지를 먼저 본다.** 이미지로 멈추고, 그 뒤에 글을 읽기 시작한다.

이미지의 역할은 세 가지다.

1. **스크롤 멈추기 (Stopping Power)** — 첫 이미지가 약하면 글을 안 읽는다
2. **이해 가속 (Cognitive Bridge)** — 글리코겐 곡선·페이스 비교 같은 정보는 그래프 한 장이 단락 세 개보다 빠르다
3. **체류 시간 (Dwell Time)** — 네이버 DIA+ 알고리즘이 이미지 수와 체류 시간을 품질 신호로 평가

따라서 이미지는 **장식이 아니라 콘텐츠 본체의 일부**다.

## 2. 채널별 이미지 밀도

| 채널 | 권장 장수 | 비고 |
|------|---------|------|
| **Journal (자사몰)** | 본문당 **5~8장** | 매거진 결, 분위기 사진 + 데이터 시각화 균형 |
| **네이버 블로그 Cluster** | 본문당 **8~13장** | "3줄 텍스트 + 1 이미지" 리듬 (모바일 표준) |
| **네이버 블로그 Pillar** | 본문당 **10~15장** | 분량이 길어진 만큼 시각 자료도 많이 |
| **인스타그램 카루셀** | **9~10장** | 슬라이드 자체가 이미지 (별도 형식, `mode_instagram.md` 참조) |

각 글에서 이미지의 종류는 다음 비율을 권장한다.

| 종류 | 비중 | 용도 |
|------|------|------|
| 분위기 사진 | 30~40% | 도입부 헤더, 섹션 전환, OUTRO |
| 데이터 시각화 (차트/그래프) | 20~30% | 숫자 비교, 곡선, 분포 |
| 다이어그램 / 인포그래픽 | 20~30% | 메커니즘 설명, 흐름도, 비교표 시각화 |
| 가상 인물·장면 (러너 액션) | 10~20% | 본문 중간 호흡 조절, 감정 자극 |

## 3. 본문 내 이미지 표기 규칙 — 마커 + 명세 섹션 분리

본문은 **마커만 삽입**하고, 글 맨 끝에 **이미지 명세 섹션**에 프롬프트와 메타정보를 모아둔다. 이 방식의 이점은 본문 가독성 유지 + GPT Image 2로 연속 생성 시 명세 섹션만 보면 되어 작업 효율이 높다는 점이다.

### 3-1. 본문 마커 형식

본문 중 이미지가 들어갈 자리에 다음 마커를 한 줄로 삽입한다.

```
[IMG-1: 도입부 헤더]
```

형식 규칙:
- 대괄호 `[ ]` 안에 작성
- `IMG-` 접두어 + 숫자(글 안에서 1부터 순차)
- `:` + 공백 + **짧은 식별명**
- 식별명은 5~10자 이내로 간결하게 (예: "도입부 헤더", "글리코겐 곡선", "두 부류 비교", "800kcal 인포그래픽")
- 마커는 **단독 줄에 배치**한다. 다른 텍스트와 같은 줄에 두지 않는다.

좋은 예:
```
30km 표지판을 지난 러너 중 절반의 페이스가 무너진다.

[IMG-1: 도입부 헤더]

> **핵심 요약**
> 30km에서 무너지는 일은 정해진 계산이다...
```

나쁜 예:
```
30km 표지판을 지난 러너 중 절반의 페이스가 무너진다. [IMG-1] 다음 문장... ❌ (인라인 배치)
[IMG1] ❌ (콜론·식별명 누락)
[이미지 1: 도입부 헤더] ❌ (접두어 형식 불일치)
```

### 3-2. 이미지 명세 섹션 — 글 맨 끝에 배치

본문 종료(면책 문구 / 참고문헌 다음) 후, 마지막 섹션으로 다음 형식을 따른다.

```markdown
---

## 이미지 명세

> GPT Image 2(GPT-4o Image Generation)로 생성. 각 명세의 프롬프트를 그대로 복사해 사용한다.

### IMG-1 — 도입부 헤더

- **종류**: 분위기 사진
- **위치**: 제목 직후, 핵심 요약박스 직전
- **위치 의도**: 글의 첫인상. 30km 표지판을 지나는 순간의 정적.
- **비율**: 21:9
- **alt 텍스트**: "마라톤 30km 표지판을 지나는 러너의 새벽 풍경"
- **캡션**: "30km. 풀코스의 약 70% 지점."

**프롬프트 (GPT Image 2)**:
> A cinematic editorial photograph of a male Korean runner
> in his late 30s, lean build, passing a '30km' course marker
> on an empty urban marathon route at early dawn. Setting:
> 5 AM, light mist hanging over the asphalt, the road still
> wet from overnight dew, cool morning light just before
> sunrise. (이하 생략)

---

### IMG-2 — 두 연료 비교 다이어그램

- **종류**: 다이어그램
- **위치**: H2-1, "두 가지 연료" 언급 직후
- **위치 의도**: 두 연료의 성격 차이를 한눈에 보여주어 본문 이해를 돕는다.
- **비율**: 4:5
- **alt 텍스트**: "글리코겐과 지방의 저장량과 분해 속도 비교 다이어그램"
- **캡션**: "두 연료, 다른 속도. 마라톤은 둘을 동시에 쓴다."

**프롬프트 (GPT Image 2)**:
> An editorial-style conceptual diagram explaining...
```

### 3-3. 명세 섹션의 항목 설명

- **종류**: 다섯 가지 중 하나 (분위기 사진 / 데이터 시각화 / 다이어그램 / 인포그래픽 / 인물 장면)
- **위치**: 본문 마커가 어느 섹션에 있는지 (예: "INTRO 끝", "H2-1 비교표 직후", "OUTRO 직전")
- **위치 의도**: 작성자(이정훈)가 검토 시 "왜 여기?" 답을 즉시 알도록
- **비율**: 채널별 표준 (§6 참조)
- **alt 텍스트**: 검색 노출용. 키워드 1개 자연 삽입, 한 줄, 따옴표 안에
- **캡션**: 이미지 아래 출력될 한 줄 (선택). 채널 톤에 맞춰 작성 (Journal=매거진 톤, 네이버=친근 톤)
- **프롬프트**: GPT Image 2에 그대로 붙여넣을 자연어 프롬프트. 인용 블록(`>`)으로 감싸서 가독성 확보

### 3-4. 마커-명세 동기화

마커 번호와 명세 섹션의 IMG 번호는 **반드시 일치**한다.

- 본문에 `[IMG-3]`이 있으면 명세 섹션에도 `### IMG-3`이 있어야 한다
- 마커 추가/삭제 시 명세 섹션도 함께 수정
- 누락된 마커, 고아 명세는 출력 전 5중 체크리스트의 "이미지 체크" 항목에서 잡는다

### 3-5. 본문 흐름 원칙

마커는 본문 흐름을 끊지 않는 자리에 배치한다.

- **한 단락 끝나고 다음 단락 시작 전** — 가장 권장
- **데이터 시각화는 표/숫자 언급 직후 또는 직전** — 인지 부하 감소
- **분위기 사진은 H2 시작 직전 또는 INTRO 끝** — 섹션 전환 마커 역할

본문 한 단락 안에 마커를 끼워 넣지 않는다. 단락이 끝난 빈 줄 뒤에 단독으로 한 줄 배치한다.

## 4. 이미지 종류별 프롬프트 패턴

GPT Image 2는 자연어 서술을 매우 잘 따른다. 키워드 나열보다 **문장으로 서술**하는 편이 결과가 좋다. 핵심 원칙: **장면 + 카메라 언어 + 색감 + 분위기 + 비율**.

### 4-1. 분위기 사진 (Atmospheric Photography)

용도: 도입부 헤더, 섹션 전환, OUTRO 회수 장면

**프롬프트 템플릿:**
```
A cinematic editorial photograph of [장면 주체 + 행동].
Setting: [시간 + 장소 + 날씨/조명].
Composition: [카메라 각도 + 거리 + 구도].
Face direction: prefer rear view, side profile, silhouette,
cropped body, or face partially hidden by cap/sunglasses;
avoid clear frontal face close-ups.
Wardrobe and gear: realistic Korean runner styling —
technical running shirt, split shorts or tights, cap, sports
sunglasses, GPS watch, arm sleeves, gloves, lightweight neck
gaiter, running belt, technical running vest or hydration vest
when context fits.
Color grade: [색감 — 우리 브랜드는 cool blue-grey base].
Mood: [감정 — quiet intensity / contemplative / determined].
Style: editorial magazine aesthetic, similar to Magazine B
or Long Black publications. Korean editorial photography.
No text overlay. [비율].
```

**예시 — Journal №01-A 도입부:**
```
A cinematic editorial photograph of a male runner passing a
"30km" course marker on an empty road
at early dawn. Setting: 5 AM, urban marathon course, light
mist, asphalt still wet from overnight dew, cool morning
light just before sunrise. Composition: low-angle shot from
behind, runner's silhouette against the soft grey horizon,
the "30km" sign in sharp focus on the right third.
Wardrobe: low-profile running cap, sports sunglasses,
technical running vest, GPS watch, black shorts, road racing
shoes. The runner's face is not clearly visible.
Color grade: cool blue-grey with muted teal shadows,
desaturated highlights. Mood: quiet intensity, the moment
just before fatigue sets in. Style: editorial magazine
aesthetic similar to Magazine B, Korean editorial
photography. No text overlay. 16:9 aspect ratio.
```

**금기:**
- 활짝 웃는 표정 (스톡 사진 톤)
- 정면 얼굴 클로즈업, 카메라를 바라보는 포즈
- 화려한 색감, 과한 채도
- 텍스트 오버레이 (본문이 텍스트라 충돌)
- 외국인 모델 위주 (타겟이 한국 러너)

### 4-2. 데이터 시각화 (Data Visualization)

용도: 글리코겐 곡선, 페이스 분포, 부류별 비교, 시간 흐름

GPT Image 2는 차트도 만들 수 있지만, **숫자와 라벨을 명시적으로 적어줘야** 정확하다. 수학 그래프보다는 **편집 디자인 결의 인포그래픽 차트**를 만드는 게 강점이다.

**프롬프트 템플릿:**
```
An editorial-style infographic chart titled "[차트 제목]".
Chart type: [line chart / bar chart / area chart / donut /
scatter plot / comparison panel].

Data:
- [축 라벨, 값 — 모두 명시]
- [축 라벨, 값 — 모두 명시]
- [...]

Visual style: minimalist, magazine editorial design.
Background: off-white (#FAFAF7).
Primary color: deep navy (#1A2B3C) for main data.
Accent color: warm orange (#E8743C) for highlight points.
Typography: clean sans-serif (similar to Inter or
Pretendard), Korean labels rendered correctly.
Annotations: [강조할 지점 — 화살표 + 한 줄 라벨].
Style reference: New York Times graphics, FT Visual,
Bloomberg Businessweek charts. No 3D effects, no shadows,
flat clean editorial style. [비율].
```

**예시 — 글리코겐 잔량 곡선:**
```
An editorial-style infographic chart titled "마라톤 진행에
따른 글리코겐 잔량 변화".
Chart type: line chart with two lines.

X-axis: distance in kilometers, from 0 to 42, with marks
at 0, 10, 20, 30, 42.
Y-axis: glycogen remaining, percentage from 0 to 100%,
with marks at 0%, 25%, 50%, 75%, 100%.

Two lines:
- Line 1 (labeled "부류 A — 빠른 페이스"): starts at 100%,
  drops to 80% at 10km, 55% at 20km, 15% at 30km, 5% at 42km.
  Drawn in warm orange (#E8743C).
- Line 2 (labeled "부류 B — 존2 훈련 중심"): starts at 100%,
  drops to 90% at 10km, 70% at 20km, 35% at 30km, 15% at 42km.
  Drawn in deep navy (#1A2B3C).

Annotations: a horizontal dashed line at 20% labeled
"비상 전환 구간". A vertical dashed line at 30km labeled
"임계 지점".

Visual style: minimalist editorial design, off-white
background (#FAFAF7), clean sans-serif typography
(Pretendard for Korean). Style reference: New York Times
data graphics. No 3D, no shadows, flat clean design.
16:9 aspect ratio.
```

**팁:**
- 데이터 값은 반드시 **명시적으로 다 적는다.** "감소하는 그래프" 같은 추상 지시는 부정확한 결과로 나옴
- 한국어 라벨이 들어가는 경우 **Pretendard·Noto Sans KR** 같은 폰트를 명시
- 강조 포인트(annotation)는 화살표·점선·박스로 명시 지시

### 4-3. 다이어그램 (Conceptual Diagram)

용도: 에너지 시스템, 흐름도, 메커니즘 설명, 비교 구조

**프롬프트 템플릿:**
```
An editorial-style conceptual diagram explaining [개념].
Layout: [horizontal flow / vertical stack / circular / 
side-by-side comparison / hub and spoke].

Elements:
- [요소 1: 위치 + 라벨 + 모양]
- [요소 2: 위치 + 라벨 + 모양]
- [...]
- Connections: [연결 관계 — 화살표/선/점선]

Visual style: minimalist line illustration, off-white
background (#FAFAF7), deep navy (#1A2B3C) lines, warm
orange (#E8743C) for accent. Korean labels in Pretendard
font, rendered correctly. Style reference: editorial
infographics from Wired, Quartz, or Bloomberg. No 3D,
flat clean design. [비율].
```

### 4-4. 인포그래픽 (Information Graphic)

용도: 숫자 강조, 통계 시각화, 단일 핵심 사실의 시각화

**프롬프트 템플릿:**
```
An editorial-style infographic poster centered on the
single fact: "[핵심 숫자/사실]".

Main element: large bold number "[숫자]" rendered in deep
navy, occupying the upper-center portion. Below the number,
a one-line label "[설명]" in smaller weight.

Supporting elements: [보조 시각 요소 — 작은 차트, 아이콘,
숫자 비교 등].

Background: off-white (#FAFAF7).
Typography: bold sans-serif (Pretendard for Korean),
editorial weight contrast.
Accent: warm orange (#E8743C) on a single visual element.
Style reference: editorial infographics from Magazine B,
Long Black, or NYT print graphics. Clean, minimal,
high contrast. [비율].
```

### 4-5. 인물 장면 (Character Scene)

용도: 본문 중간 감정 환기, 케이스 시각화, 카루셀 슬라이드

**프롬프트 템플릿:**
```
A cinematic editorial photograph of [인물 묘사 + 행동 + 감정].
Setting: [장소 + 시간 + 조명].
Wardrobe: [복장 — 러닝 의류, 색상 명시].
Gear: [실제 러너 장비 — 러닝 캡, 선글라스, GPS watch,
러닝 조끼/하이드레이션 베스트, 러닝 벨트, 장갑, 암슬리브 등].
Face direction: [후면 / 측면 / 실루엣 / 얼굴이 캡이나 선글라스로 일부 가려짐].
Composition: [샷 사이즈 + 각도]. Avoid clear frontal
face close-ups and camera-facing portraits.
Color grade: cool blue-grey base, desaturated, editorial
photography.
Mood: [감정 톤].
Style: Korean editorial photography, similar to Magazine B
or running culture publications. Authentic, not staged.
No text overlay. [비율].
```

## 5. 브랜드 비주얼 톤 — 일관성을 위한 고정 요소

모든 이미지에 다음 5요소를 일관되게 적용한다. 이게 흩어지면 글마다 분위기가 달라져서 브랜드 인상이 만들어지지 않는다.

### 5-1. 컬러 팔레트

| 역할 | 컬러 | HEX | 용도 |
|------|------|------|------|
| 베이스 | 오프 화이트 | `#FAFAF7` | 배경 |
| 메인 | 딥 네이비 | `#1A2B3C` | 주요 데이터, 텍스트, 라인 |
| 액센트 | 웜 오렌지 | `#E8743C` | 강조 포인트, 핵심 숫자 |
| 보조 | 쿨 그레이 | `#6B7280` | 부수 데이터, 라벨 |
| 분위기 | 쿨 블루-그레이 | (사진 색감) | 모든 분위기 사진 색 보정 |

**금기 컬러**: 빨강·분홍 (의약품 연상), 형광색·네온 (저렴한 에너지 드링크 톤), 골드·금색 (보양식 톤).

### 5-2. 타이포그래피 (이미지 내 텍스트가 들어갈 때)

- 한국어: **Pretendard** 또는 Noto Sans KR
- 영문: Inter / Söhne / Helvetica Neue
- 절대 금지: 손글씨체, 둥근 폰트, 장식적 폰트

### 5-3. 분위기 키워드 (모든 사진 공통)

다음 키워드를 사진 프롬프트에 거의 항상 포함한다.

- `editorial magazine aesthetic` (매거진 결)
- `cool blue-grey color grade` (브랜드 색감)
- `quiet intensity` 또는 `contemplative` (감정 톤)
- `Korean editorial photography` (인물이 한국인이어야 할 때)
- `no text overlay` (텍스트 충돌 방지)

### 5-4. 모델 가이드 (인물이 등장할 때)

- **연령**: 30대 후반~40대 초반 한국 남성 (제품 핵심 타겟)
- **체형**: lean build, runner's physique
- **얼굴 노출**: 정면 얼굴 클로즈업 금지. 후면, 측면, 실루엣, 고개 숙인 구도, 캡/선글라스로 일부 가려진 얼굴을 우선
- **표정**: 얼굴이 보이더라도 활짝 웃지 않음. 집중·결의·관조 중 하나
- **복장**: 러닝 의류 (검정/네이비/그레이 위주, 컬러 의류는 액센트로만)
- **장비**: 실제 러너처럼 러닝 캡, 스포츠 선글라스, GPS 워치, 암슬리브, 장갑, 러닝 벨트, 얇은 넥게이터, 러닝 조끼/하이드레이션 베스트를 맥락에 맞게 1~3개 조합
- **조끼 사용**: 트레일러닝 느낌의 과장된 대형 배낭은 피하고, 로드 러너도 쓸 법한 낮은 부피의 technical running vest 또는 hydration vest로 표현
- **금기**: 외국인 단독, 과도하게 근육질, 어린 모델, 여성 단독 (확장 타겟이지만 Phase 1에서는 남성 위주)

### 5-5. 레퍼런스 매체

프롬프트에 자주 언급할 스타일 레퍼런스:

- **사진**: Magazine B, Long Black, Monocle, Cereal Magazine
- **차트**: New York Times graphics, Financial Times Visual, Bloomberg Businessweek
- **다이어그램**: Wired, Quartz, Information is Beautiful

## 7. 이미지 체크리스트 (5중 체크의 5번째)

기존 4중 체크리스트(규제 / AEO / 내부링크 / 흡입력)에 다음을 추가한다.

### 이미지 체크 (5항목)

- [ ] **장수 충족**: Journal 5~8장 / 네이버 Cluster 8~13장 / Pillar 10~15장 / 카루셀 9~10장
- [ ] **종류 균형**: 분위기 사진 / 데이터 시각화 / 다이어그램 / 인물 장면 중 최소 3종 혼합
- [ ] **마커-명세 동기화**: 본문의 모든 `[IMG-N: 식별명]` 마커가 명세 섹션의 `### IMG-N`과 1:1 일치
- [ ] **프롬프트 완결성 + 브랜드 톤**: 모든 명세에 GPT Image 2에 그대로 붙여넣을 수 있는 자연어 프롬프트 + 컬러 팔레트 / 분위기 키워드 / 비율 표준 일관성
- [ ] **alt 텍스트 + 캡션**: 모든 이미지 명세에 alt(SEO) 명시 + (선택) 채널 톤 캡션

## 8. 규제 — 이미지에서도 적용

이미지에도 본문과 같은 규제가 적용된다. 다음을 절대 생성하지 않는다.

### 8-1. 채널 무관 절대 금지

- 제품 사진 (지구력코어 패키지·정제 이미지 일체)
- "지구력코어" "옥타코사놀" 텍스트가 들어간 이미지
- 알약·캡슐을 손에 들고 있는 장면 (의약품 연상)
- "지구력 증진" "에너지 부스트" "스테미너" 등 5대 금지어 텍스트
- 의사·의료진 캐릭터, 흰 가운, 청진기 (의약품 오인)
- 환자 침대, 병원 장면

### 8-2. TOFU 추가 금지 (네이버 블로그 / Journal 본문)

- 어떤 형태로든 알약·캡슐·정제 시각화
- 영양제·건기식 통·병 일러스트
- 운동 후 보충제 섭취 장면

### 8-3. MOFU/BOFU 허용 (단, 사전심의 영역)

- 제품 사진 (BOFU만)
- 알약 장면 (MOFU 구획 분리 후 + 심의 후)
- 단, 모두 사전심의 통과 후에만 사용

## 9. 작업 흐름 — 글 작성 시 이미지 처리

1. **글의 H2 구조 확정 후 이미지 위치 미리 잡는다** — 본문 작성 전에 어디에 어떤 이미지가 들어갈지 윤곽을 그려둔다
2. **본문 작성 중에 마커 삽입** — `[IMG-1: 도입부 헤더]` 같은 한 줄 마커를 단독 줄에 배치
3. **본문 종료 후 "이미지 명세" 섹션에 명세 작성** — 마커 번호 순서대로 ### IMG-1, ### IMG-2, ... 정리
4. **프롬프트는 §4 템플릿에서 시작** — 종류 선택 후 템플릿에 값 채우기
5. **§5 브랜드 톤 5요소 점검** — 컬러·폰트·분위기 키워드·모델·레퍼런스
6. **§7 이미지 체크리스트 실행** — 5항목 점검 (마커-명세 동기화 필수)
7. **사용자(이정훈)가 명세 섹션에서 프롬프트 순서대로 GPT Image 2 생성** — IMG-1부터 IMG-N까지 연속 작업
8. **결과물 검토 → 필요 시 명세 섹션의 프롬프트 수정 후 재생성**

## 10. 프롬프트 작성 시 자주 쓰는 빌딩 블록

빠른 작성을 위해 자주 쓰는 구문을 모아둔다. 새 프롬프트 짤 때 이 블록을 조합한다.

### 10-1. 분위기·색감 블록

- `editorial magazine aesthetic, Magazine B style`
- `cool blue-grey color grade, desaturated highlights`
- `quiet intensity, contemplative mood`
- `Korean editorial photography`
- `cinematic composition, low-angle shot`
- `soft morning light, slight mist`

### 10-2. 데이터 시각화 블록

- `minimalist editorial infographic, off-white background (#FAFAF7)`
- `deep navy (#1A2B3C) primary, warm orange (#E8743C) accent`
- `Pretendard font for Korean labels, rendered correctly`
- `style reference: New York Times graphics, Financial Times Visual`
- `flat clean design, no 3D effects, no shadows`

### 10-3. 다이어그램 블록

- `editorial conceptual diagram, minimalist line illustration`
- `deep navy lines on off-white background`
- `Korean labels in Pretendard, rendered correctly`
- `style reference: Wired infographics, Quartz visualizations`

### 10-4. 인물 장면 블록

- `Korean male runner in his late 30s, lean build`
- `rear view or side profile, face not clearly visible`
- `low-profile running cap, sports sunglasses, GPS watch`
- `technical running vest or lightweight hydration vest when context fits`
- `wardrobe: black/navy/grey running gear, no logos visible`
- `authentic candid feel, not staged`
- `editorial photography, similar to Magazine B running features`

### 10-5. 비율 블록

- `16:9 aspect ratio` (와이드 헤더)
- `4:5 aspect ratio` (네이버 본문, 인스타 피드)
- `1:1 aspect ratio` (인스타 정방형, 인포그래픽 포스터)
- `9:16 aspect ratio` (스토리, 릴스)
