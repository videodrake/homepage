## 1. 법적 근거 한눈에 보기

| 구분 | 핵심 내용 | 조항 |
|------|-----------|------|
| 사전심의 의무 | 건기식 표시·광고는 자율심의기구(한국건강기능식품협회)에서 **사전심의 필수** | 법 제10조 제1항 |
| 심의 면제 | 법정 표시사항만 그대로 표시·광고하는 경우 면제 | 법 제10조 제1항 단서 |
| 부당 표시·광고 금지 | 질병 예방·치료 효능 인식 우려 표현 등 10가지 유형 금지 | 법 제8조 제1항 |
| 벌칙 (질병 표현) | 10년 이하 징역 또는 1억원 이하 벌금 (병과 가능) | 법 제26조 |
| 벌칙 (기타 위반) | 5년 이하 징역 또는 5천만원 이하 벌금 (병과 가능) | 법 제27조 |
| 심의 미필 광고 | 심의 없이 광고 = 부당 광고로 간주 → 제27조 적용 | 법 제8조 제1항 제10호 |

## 2. 옥타코사놀 함유 유지 — 유일한 인정 기능성

```
"지구력 증진에 도움을 줄 수 있음"
```

**이 문장이 허용 범위의 전부입니다.** 이 범위를 벗어나는 모든 표현은 위반입니다.

## 3. 옥타코사놀 5대 금지 표현 (공통심의기준 品目별 가이드라인)

| # | 금지 표현 | 금지 사유 |
|---|-----------|-----------|
| 1 | **스테미너** | 남성 성기능 향상 암시 — 기능성 내용과 무관 |
| 2 | **피로 / 피곤** | 피로개선(홍삼 등) 기능성으로 오인 — 지구력과 다른 기능성 범주 |
| 3 | **파워 / 파워업** | 기능성 범위 초과 표현 |
| 4 | **젊음 / 젊다** | 기능성 범위 초과 표현 ("젊음이 되돌아온 기분" 등) |
| 5 | **힘없는** | 기능성 범위 초과 표현 ("힘없는 중년" 등) |

### 추가 금지 표현 (공통심의기준에서 확인)
- "늦둥이 부스터샷" — 기능성 왜곡 (부스터 관련 가이드라인 위반)
- "운동 능력의 새로운 기준", "퍼포먼스 시스템" — 과장 표현, 기능성 초과
- "완벽히", "보장합니다", "확실하게" — 단정적 표현 일체 금지

## 4. 적합 vs 부적합 표현 사례 (공통심의기준 안내서 기준)

### ✅ 적합 표현
- "운동 과학이 입증한 지구력의 혁신, 옥타코사놀이 선사하는 에너지가 완성됩니다"
- "컨디션 관리의 프리미엄 솔루션, 옥타코사놀이 당신의 활력있는 일상을 실현합니다"
- "옥타코사놀로 지속가능한 활력이 시작됩니다"
- "운동 시 지구력 향상에 도움을 줄 수 있는 옥타코사놀 함유 유지"
- "스포츠 과학으로 설계된 지구력 지원 솔루션"
- "운동 시 컨디션 관리와 에너지 대사에 도움을 줄 수 있습니다"

**적합 사유**: 허용 기능성 범위 내, 효과를 간접 암시(단정 아님), 의약품 오인 방지, 보조적 역할 강조

### ❌ 부적합 표현
- "과학적으로 설계된 퍼포먼스 시스템, 옥타코사놀이 운동 능력의 새로운 기준을 제시합니다"
- "단단한 연골 재생을 보장합니다" (범위 외)
- 성기능 암시 표현 일체 ("이게 된다고?", "아내가 좋다고 계속 먹으라고 해요" 등)

**부적합 사유**: 기능성 초과, 소비자 기대 과도 유발, 의약품 오인

## 6. 퍼널별 규제 적용 룰

### TOFU (인지/관심 단계) — 교육 콘텐츠
- **제품명 / 브랜드명**: 완전 제거
- **기능성 표현**: 없음 (순수 교육 정보만)
- **사전심의**: 불필요
- **면책 문구**: 불필요
- **핵심 원리**: 제품과 1mm도 연결되지 않는 순수 교육 콘텐츠 → 식표법 적용 대상 아님

### MOFU (검색/비교 단계) — 건강정보 + 제품정보 분리
- **건강정보와 제품정보 구획 분리 필수** (공통심의기준 제10항)
  - 건강정보는 한 곳에 모아 **맨 뒤로 배열**
  - 제품정보와 **구획선으로 명확히 분리**
  - 출처(학술문헌, 통계자료 등) 반드시 함께 명시
  - **"본 정보는 제품정보와 관련 없는 내용입니다"** 문구 필수 삽입
- **기능성 표현 포함 시**: 사전심의 필요
- **기능성 표현 없이 제품 단순 소개만**: 사전심의 조건부 (표시사항 그대로면 면제)

### BOFU (구매/공유 단계) — 완전 규제 대상
- **사전심의 반드시 필요**
- 기능성 표현은 **인정 문구 범위 내**에서만
- 심의 결과에 따라 표시·광고 (법 제10조 제4항)
- 광고에 **심의필 도안 또는 "이 광고는 표시·광고심의위원회의 심의를 받은 내용입니다" 문구** 표시 가능

## 7. 광고시안 작성 시 필수 포함 사항

건기식 광고 시 반드시 포함해야 하는 항목 (법 제7조, 공통심의기준):
1. **제품명** (품목제조신고증 기재 명칭 그대로)
2. **업소명** (제조업소명 + 판매업소명)
3. **건강기능식품임을 알리는 내용**
4. 주원료와 부원료 **명확히 구분**
5. 부원료 기능성 암시/강조 금지

---

## 8. 학술문헌 / 연구자료 인용 규칙

콘텐츠에 학술 자료를 인용할 때 지켜야 할 규칙 (공통심의기준 Ⅲ-2-가):

1. **SCI급 학술지** 게재 논문이어야 함 (국내: 한국연구재단 등재학술지)
2. 식약처장이 인정한 **기능성 범위 내** 연구 내용만 인용 가능
3. 질병 치료·의약품 오인 우려 연구 내용은 인용 불가
4. 연구자료(그래프, 도표) 인용 시 **원문 그대로** 또는 원문 의미 불변 범위 내
5. **"인체적용시험결과가 모든 사람에게 동일하게 적용되는 것은 아님"** 병기 필수
6. 시험관/동물실험 인용 시 **"시험관(동물)실험결과 OOO 개선이 확인되었으나 인체에는 동일하게 작용하지 않을 수 있음"** 병기 필수

### TOFU 콘텐츠에서의 학술 인용
- TOFU는 제품과 무관한 교육 콘텐츠이므로, 일반 운동과학/영양학 논문 인용은 자유
- 다만 "옥타코사놀" 원료명을 직접 거론하면 MOFU로 전환됨 → 규제 수준 상승
- 안전한 접근: "특정 천연 성분이~", "일부 연구에 따르면~" 등 원료 비특정 표현

---

## 9. 체험사례 / 후기 관련 규칙

1. 식약처 인정 기능성 범위 내 표현만 가능
2. 질병 치료 효과 암시 금지 (예: "OO제품 먹고 XX kg 감량" ❌)
3. 실존 인물이어야 함 (가상 인물 후기 금지)
4. 연예인/일반인 추천·보증은 실제 사용 경험 기반 + 기능성 범위 내만 가능
5. 의사·한의사 등 전문가 인용은 해당 제품 연구·개발 직접 참여자에 한해 가능 (증빙 필수)

## 10. 유일·최상급 표현 규칙

| 표현 | 허용 여부 | 조건 |
|------|-----------|------|
| 유일 | ❌ 금지 | 환경 변화로 변동 가능 → "최초"로 대체 |
| 최초 | ✅ 허용 | 객관적 입증 가능한 경우 |
| 최고, 최상 | ❌ 금지 | 비교기준 불명확 |
| 최대 | ⚠️ 조건부 | 기능성 관련은 부적합, 객관적 데이터 있으면 가능 |
| 최대함량 | ⚠️ 조건부 | 비교기준 명확 시 허용 (예: "식약처 일일섭취량대비 최대함량") |
| 고단위/고순도/고농도 | ❌ 금지 | 기준 불명확 |
| 새로운 패러다임, 신개념 | ❌ 금지 (기능성 관련) | 제형·맛 관련은 허용 가능 |

## 빠른 판단 플로차트

```
글에 제품명/브랜드명이 있는가?
├─ 없음 → 기능성 표현이 있는가?
│         ├─ 없음 → TOFU ✅ 심의 불필요
│         └─ 있음 → "옥타코사놀"이 특정되는가?
│                   ├─ 아님 (일반 교육) → TOFU ✅ 심의 불필요
│                   └─ 특정됨 → MOFU ⚠️ 심의 검토 필요
└─ 있음 → 기능성 표현이 있는가?
          ├─ 없음 (제품 단순 소개) → MOFU ⚠️ 구획분리+면책문구 필요
          └─ 있음 → BOFU 🔴 사전심의 필수
```
