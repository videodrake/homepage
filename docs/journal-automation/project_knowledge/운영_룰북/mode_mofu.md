# mode_mofu.md

> 네이버 블로그 MOFU 작성 시 로드되는 모드 가이드. **현재 활성 채널이 아님** — 미래 사용처를 위한 룰북 보존.
> v2 (2026-04-28). 이미지 섹션(§4-5) 추가. 5중 체크리스트로 확장.

---

## 1. 채널 정의와 현재 위치

### 1-1. MOFU의 위상

MOFU는 "건강정보 + 제품정보 구획 분리" 방식의 글을 의미한다. 한 글 안에 교육 파트(구획 A)와 제품 파트(구획 B)를 명확히 분리해 발행하는 채널이다.

### 1-2. 현재 활성 여부 — **비활성**

현재 콘텐츠 파이프라인에서 MOFU 글은 발행하지 않는다.

- 자사몰 Journal은 본문 내 제품·기능성 0회로 작성하며, 끝까지 건강정보로만 닫는다 (사실상 TOFU 톤)
- 네이버 블로그는 TOFU만 발행한다
- 자사몰 BOFU/제품 페이지는 사전심의 필수 영역으로 별도 워크플로우 적용

이 조건에서 "구획 분리 MOFU" 글은 발행처가 없다. 따라서 이 모드는 **현재 호출되지 않는다.**

### 1-3. 룰북을 보존하는 이유

다음 상황이 발생하면 MOFU 모드가 다시 활성화될 수 있다.

- 자사몰 외 별도 SEO 사이트를 운영할 때
- 네이버 블로그 정책 변화로 일부 MOFU 발행이 가능해질 때
- 제휴 매체에 글을 기고할 때
- 사전심의 통과한 콘텐츠를 더 폭넓게 활용할 때

이 가능성에 대비해 3-Zone 구조 룰북을 보존한다. 활성화 시점에 이 모드를 호출한다.

## 2. 3-Zone 구조 (활성화 시 준수)

모든 MOFU 글은 다음 3-Zone 모델로 구성한다: 구획 A → 구분선 → 구획 B → 구획 C.

### 2-1. 구획 A — 성분 과학 교육 (글 전체의 60~70%)

- 학술 논문·공식 자료 기반 순수 정보 제공
- 옥타코사놀의 과학적 메커니즘, 연구 현황 등 객관적 서술
- 제품명 "지구력코어" 절대 금지
- 구매 유도·추천 표현 금지
- 다른 성분과의 비교 가능 (객관적 데이터 기반)
- AEO 3요소는 구획 A에만 적용 (요약박스, 비교표, FAQ)
- "이 구획만 읽어도 완전한 가치를 제공"하는 것이 핵심 원칙

구획 A 말미 면책 문구 (필수):

```
※ 본 내용은 특정 제품의 광고가 아닌, 공개된 학술 자료에 기반한 일반적인 성분 정보입니다.
```

### 2-2. 구분선 (필수)

```
---
⚠️ 아래 내용은 관련 건강기능식품 제품 정보를 포함합니다.
---
```

구획 A와 B 사이에 반드시 시각적 경계선 + 고지 문구를 삽입한다.

### 2-3. 구획 B — 제품/성분 정보 (글 전체의 15~25%)

- 제품명 "지구력코어" 사용 가능
- 인정 기능성 문구만 사용: "지구력 증진에 도움을 줄 수 있음"
- 이 문구의 변형·강화·축약 금지
- 심의번호 표기 필수
- 원재료, 섭취 방법, 용량 등 사실 정보만

구획 B 상단 면책 문구 (필수):

```
※ 본 제품은 질병의 예방 및 치료를 위한 의약품이 아닙니다.
```

### 2-4. 구획 C — 공정위 고지 + CTA (글 전체의 5~10%)

- 본문 첫 부분 광고 표기 법적 의무 (2024.12 공정위 개정안)
- 구매 링크 (자사몰, 스마트스토어 등)
- "이 글은 [브랜드명]의 제품 정보를 포함하고 있습니다" 고지

## 3. 구획 분리 위반 사례 (절대 금지)

| 위반 | 사유 |
|------|------|
| 구획 A에서 "그래서 지구력코어를 만들었습니다" | A에서 제품명 등장 → 교육 파트가 광고로 전환 |
| 구획 A에서 "이 성분이 들어간 제품을 고를 때" | 구매 유도 암시 → A의 교육 독립성 훼손 |
| 구획 B에서 "옥타코사놀이 지구력을 폭발적으로 높여줍니다" | 인정 기능성 범위 초과 + 금지 표현 |
| 구분선 없이 A→B 자연 전환 | 구획 미분리 → 전체가 광고로 판정 |
| 구획 A의 FAQ에서 "지구력코어가 도움이 될까요?" | A 내 FAQ에도 제품명 금지 |
| 구획 A 이미지에 제품 사진·알약 등장 | A의 시각적 광고 전환 — 텍스트와 동일 위반 |
| 구획 A 이미지 내 텍스트에 "지구력코어"·"옥타코사놀" 노출 | OCR 탐지 위반 |

## 4. 본문 구조 템플릿 (활성화 시)

```
제목: 성분 중심 교육 제목 (예: "옥타코사놀이란? — 러너가 알아야 할 과학적 근거")

[구획 A: 성분 과학 교육]

  [IMG-A1: 헤더 분위기] 마커 — 분위기 사진, 제품/알약 절대 금지

  [핵심 요약박스] ← AEO 필수 (구획 A 범위 내에서만)
  > **핵심 요약**
  > [한 문장 직접 답변]
  > - 부연 불렛 3~5개 (제품명 금지)

  H2: 성분 개요
    H3: 정의와 유래
    H3: 작용 메커니즘 (논문 기반)
    [비교표] ← AEO 필수
    [IMG-A2: 작용 메커니즘 다이어그램] 마커

  H2: 연구 현황
    H3: 주요 연구 결과 (출처 명시)
    [IMG-A3: 연구 데이터 시각화] 마커
    H3: 한계점과 논쟁 (Strategic Honesty)

  H2: 자주 묻는 질문 ← AEO 필수
    Q&A 3~5개 (제품명 금지)

  ※ 면책 문구

  [함께 읽으면 좋은 글] ← 내부링크 (TOFU 글로만 연결)

---
⚠️ 아래 내용은 관련 건강기능식품 제품 정보를 포함합니다.
---

[구획 B: 제품 정보]
  ※ 본 제품은 질병의 예방 및 치료를 위한 의약품이 아닙니다.
  H2: 지구력코어 제품 안내
  - 인정 기능성: "지구력 증진에 도움을 줄 수 있음"
  - 원재료, 함량, 섭취 방법
  - 심의번호

  [IMG-B1: 제품 패키지] 마커 ← 사전심의 통과 후만 가능
  [IMG-B2: 정제 시각화] 마커 ← 사전심의 통과 후만 가능

[구획 C: 고지 + CTA]
  - 광고 표기 고지문
  - 구매 채널 링크 (자사몰, 스마트스토어 등)

[이미지 명세 섹션] ← 글 맨 끝
  - IMG-A1, A2, A3, B1, B2, C1 순서로 명세
```

분량 가이드: 글 전체 약 2,000~3,000자.
이미지: 구획 A 6~10장, 구획 B 2~4장 (사전심의 후), 구획 C 0~1장.

## 4-5. 이미지 — MOFU 모드 (구획별 분리 적용)

> 상세 프롬프트 템플릿은 `이미지_가이드.md` §4 참조.

MOFU의 이미지 규칙은 **구획별로 다르다.** 이것이 MOFU 이미지의 핵심 원칙이다. 구획 A의 이미지가 구획 B의 이미지처럼 보이면 전체가 광고로 판정된다.

### 4-5-1. 구획 A 이미지 — TOFU와 동일 규칙

구획 A는 교육 콘텐츠다. 따라서 **TOFU 이미지 규칙을 그대로 적용**한다.

- **장수**: 6~10장
- **종류**: 분위기 사진 / 데이터 시각화 / 다이어그램 / 인포그래픽 / 인물 장면 (3종+ 혼합)
- **절대 금지**: 제품 사진 / 알약·캡슐 시각화 / 영양제 통 / "지구력코어"·"옥타코사놀" 텍스트
- **컬러·톤**: 브랜드 톤 일관(`#FAFAF7` / `#1A2B3C` / `#E8743C`)
- **alt 텍스트**: 성분명 일반 표현 가능 (예: "옥타코사놀 작용기전 다이어그램") — 단, 이는 구획 A가 학술 정보 영역이므로 가능. 그러나 "지구력코어" 같은 제품명은 alt에도 금지

### 4-5-2. 구분선 영역 — 이미지 없음

구획 A와 B 사이 구분선 영역에는 이미지를 넣지 않는다. 시각적 경계 자체가 메시지이므로 추가 이미지가 들어가면 분리 효과가 약해진다.

### 4-5-3. 구획 B 이미지 — 사전심의 필수

구획 B는 제품 정보 영역이다. 다음 이미지가 가능하지만, **모두 사전심의 통과가 필수**다.

- 제품 사진 (지구력코어 패키지)
- 정제 시각화 (캡슐·알약 형태)
- 영양 정보 인포그래픽

**금지**:
- 인정 기능성 범위를 초과하는 시각적 암시 (예: "에너지가 폭발하는" 이미지)
- 의약품 연상 (의사·흰 가운·청진기·약병·처방전)
- 5대 금지어가 들어간 텍스트 오버레이

### 4-5-4. 구획 C 이미지 — 최소화

CTA 영역의 이미지는 광고 표기 고지문 + 단순한 제품 썸네일 정도. 추가 시각 강조는 권장하지 않는다.

### 4-5-5. 본문 표기 — 마커 + 명세 섹션 (구획별 표기)

본문 중 이미지가 들어가야 할 자리에 다음 마커를 단독 줄에 삽입한다. **구획 표기(A/B/C)는 마커 안에 명시**한다.

```
[IMG-A1: 헤더 분위기]            ← 구획 A (교육 영역)
[IMG-A2: 작용 메커니즘 다이어그램]   ← 구획 A
[IMG-B1: 제품 패키지]             ← 구획 B (제품 정보 — 사전심의 필수)
[IMG-C1: CTA 썸네일]              ← 구획 C (CTA)
```

본문 종료 후 글 맨 끝에 **이미지 명세 섹션**을 두고 마커 순서대로 다음 형식으로 작성한다. 명세 안에 **구획별 규제 주의사항**을 명시한다.

```markdown
---

## 이미지 명세

### IMG-A1 — 헤더 분위기 (구획 A: 교육 영역)

- 종류: 분위기 사진
- 위치: 구획 A 도입부, 핵심 요약박스 직전
- 위치 의도: [한 줄]
- 비율: 16:9
- alt 텍스트: "[키워드 자연 삽입, 한 줄 — 제품명 금지]"
- 캡션: "[교육 톤]"
- 규제: ⚠️ 구획 A — 제품 사진·알약·"지구력코어"·"옥타코사놀" 텍스트 절대 금지

**프롬프트 (GPT Image 2)**:
> [자연어 프롬프트]

---

### IMG-B1 — 제품 패키지 (구획 B: 제품 정보)

- 종류: 제품 사진
- 위치: 구획 B, 제품 안내 H2 직후
- 비율: 1:1
- alt 텍스트: "지구력코어 패키지 정면 사진"
- 규제: ⚠️ **사전심의 필수** — 심의번호 부여 후에만 사용 가능

**프롬프트 (GPT Image 2)**:
> [자연어 프롬프트]

---

(나머지 IMG-A?, IMG-B?, IMG-C? 동일 형식 반복)
```

마커 번호와 명세의 IMG 번호는 반드시 1:1 일치. 구획 표기가 마커와 명세에서 서로 다르면 안 된다 (IMG-A1 마커 ↔ IMG-A1 명세).

## 5. AEO 적용 범위 — MOFU 특수 규칙

| 요소 | 구획 A | 구획 B | 구획 C |
|------|--------|--------|--------|
| 핵심 요약박스 | ✅ 필수 | ❌ 불필요 | ❌ 불필요 |
| 비교표 | ✅ 1개+ | ❌ | ❌ |
| FAQ | ✅ 3~5개 | ❌ | ❌ |
| 이미지 | ✅ 6~10장 (TOFU 룰) | ⚠️ 2~4장 (심의 후) | 최소화 |

핵심: AEO는 구획 A의 교육적 가치를 극대화하기 위한 것이며, 구획 B/C에는 적용하지 않는다.

---

## 6. 내부링크 규칙

- 구획 A → TOFU 블로그: "관련 읽을거리" 링크 허용 ✅
- 구획 B → 자사몰 제품 페이지: 링크 허용 ✅
- TOFU → MOFU 역방향: 절대 금지 ❌ (규제 분리 원칙)
- 기발행 TOFU 글 중 관련 주제를 구획 A 하단에 1~2개 배치
- 앵커 텍스트: 키워드 포함 서술형

---

## 7. 5중 셀프체크 (활성화 시)

### 7-1. 구획 분리 체크 (9항목)

- [ ] 구획 A에 제품명 "지구력코어" 0회 (본문 + 이미지 + alt + 캡션)
- [ ] 구획 A에 구매 유도·추천 표현 0건
- [ ] 구획 A 말미 면책 문구 존재
- [ ] 시각적 경계선 + 고지 문구 존재
- [ ] 구획 B 상단 면책 문구 존재
- [ ] 구획 B에 인정 기능성 외 효능 표현 0건
- [ ] 구획 B에 "효과", "치료", "예방" 등 의약품 표현 0건
- [ ] 심의번호 기재 여부
- [ ] 구획 C에 공정위 광고 표기 고지문 존재

### 7-2. AEO 체크 (구획 A만, 4항목)

- [ ] 핵심 요약박스 존재 (구획 A 상단)
- [ ] 비교표 1개+ 존재
- [ ] FAQ 3~5개 존재 (제품명 미포함 확인)
- [ ] 구획 B/C에 AEO 요소가 포함되지 않았는지 확인

### 7-3. 내부링크 체크 (3항목)

- [ ] 구획 A에서 TOFU 기발행 글 1~2개 링크
- [ ] 구획 A에서 MOFU/BOFU/제품 페이지로 링크하지 않았는지 확인
- [ ] 구획 B에서 자사몰 링크만 존재하는지 확인

### 7-4. 흡입력 체크 (구획 A 한정, 5항목)

- [ ] 구획 A 도입부에 장면 또는 인지 갭
- [ ] 정보갭 1~2개, 구획 A 내에서 닫힘
- [ ] 종결어미 ~입니다 60~70% 변주
- [ ] 모바일 텍스트 벽 없음

## 8. 작업 흐름 (활성화 시)

사용자 요청: `MOFU 글 작성해줘 — [성분/주제]`

**설계**
1. 주제 확인 + 구획 A/B 분량 비율 결정
2. 구획 A의 One Message 정리
3. 구획 B의 제품 정보 점검 (심의번호·기능성 문구·심의 통과 이미지 보유 여부)
4. 이미지 분배 설계 (A: 6~10장 / B: 2~4장)

**작성**
5. 구획 A 작성 (헤더 IMG-A1 마커 → 본문 + 마커 4~6개)
6. 구획 A 면책 문구 → 구분선 → 구획 B 면책 문구 순서
7. 구획 B 작성 (제품 정보 + IMG-B? 마커, 심의 통과 이미지 한정)
8. 구획 C 작성 (공정위 고지 + CTA + IMG-C? 마커, 선택)
9. **이미지 명세 섹션 작성** — IMG-A1, A2,..., B1, B2, C1 순서로 명세 정리

**검수**
10. 5중 셀프체크 실행 (총 26항목) + 마커-명세 동기화 + 구획 표기 일치 검증
11. **사전심의 필요 항목 별도 표시** (구획 B 이미지·기능성 문구)
12. .md 파일 출력
