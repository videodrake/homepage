## 0. 이 문서의 핵심 한 줄

**몰입은 장식이 아니라 구조다. 정보를 '어떤 순서로, 얼마나 감춰두었다가, 언제 꺼내느냐'가 독자의 뇌를 붙잡는다.**

Loewenstein(1994)의 정보갭 이론, Gruber(2014)의 fMRI 실험, Sugarman의 Slippery Slide 원칙, 네이버 DIA+ 체류시간 가중치 — 모두 같은 것을 말합니다. 독자의 뇌는 "미완성 정보"를 해결하려는 충동을 참지 못합니다. 이 충동을 설계하는 것이 흡입력입니다.

## 1. 정보갭 설계 (Information Gap Architecture)

### 과학적 근거
- Loewenstein(1994): 호기심은 "아는 것과 모르는 것 사이의 갭을 인지할 때" 발생. **완전한 무지는 호기심을 만들지 못한다.** 부분적 지식이 있을 때 가장 강하다.
- Gruber, Gelman & Ranganath(2014, *Neuron*): 호기심 상태에서 중뇌(SN/VTA)와 측좌핵(nucleus accumbens) 활성화 — 음식, 금전 보상과 같은 도파민 회로. **호기심 상태에서는 관련 없는 정보의 기억도 함께 향상된다** (spillover effect).
- 실용적 의미: 글 도입부에서 정확한 정보갭을 만들면, 그 글의 **모든 내용**이 더 잘 기억된다.

### 실행 규칙

**규칙 1-1: 모든 글은 "프라이밍 도즈 → 갭 → 해소"로 설계한다.**

```
[프라이밍 도즈] 독자가 이미 아는 것을 확인시킨다
         ↓
[갭 생성] "그런데 이것만으로는 설명이 안 되는 부분이 있다"
         ↓
[1~3문단의 서스펜스] 다른 내용을 먼저 전달
         ↓
[갭 해소] 답을 준다
```

**규칙 1-2: 글 1편당 정보갭 2~3개. 위치를 사전에 지정한다.**

| 위치 | 갭의 역할 | 해소 시점 |
|------|----------|----------|
| 도입부 (첫 3문장) | "이 글을 왜 끝까지 읽어야 하는가" | 결론 직전 |
| 본론 1→2 전환 | "아직 모르는 게 하나 더 있다" | 본론 2 중간 |
| (선택) 본론 2→결론 전환 | "이걸 실제로 적용하면 어떻게 되는가" | 결론 |

**규칙 1-3: 열린 갭은 반드시 닫는다. 안 닫으면 클릭베이트다.**
- Masicampo & Baumeister(2011): 미해결 목표는 침입적 사고를 유발하지만, 구체적 완료 계획이 생기면 해소된다.
- 글에서 연 갭을 닫지 않으면 → 독자의 뇌가 "이 글은 답이 없구나" 판단 → 신뢰 훼손.

### 한국어 갭 생성 패턴

**사용할 것:**
- "그런데 이게 전부가 아닙니다."
- "원인은 예상과 다른 곳에 있습니다."
- "숫자를 보면 더 명확해집니다."
- "문제는 여기서부터입니다."
- "이유가 하나 더 있습니다."

**금지할 것:**
- "놀라운 사실이 있습니다!" — 과장. Sage 아키타입과 충돌.
- "비밀을 알려드리겠습니다" — 세일즈 톤.
- "아무도 모르는" — 독자를 무시하는 느낌.
- "충격적인" — 클릭베이트 시그널.

## 2. 서사 이동 (Narrative Transportation)

### 과학적 근거
- Green & Brock(2000, *JPSP*): 서사에 "이동(transported)"된 독자는 반론을 덜 생성하고, 태도가 이야기 방향으로 더 많이 이동한다.
- Braddock & Dillard(2016) 메타분석: 서사 노출은 믿음(r=.17), 태도(r=.19), 의도(r=.17), 행동(r=.23)에 유의미한 영향.
- Van Laer et al.(2019): **사용자 생성 스토리**가 전문 제작 스토리보다 서사 이동 효과가 더 크다 — 블로그에 직접적으로 유리한 발견.

### 실행 규칙

**규칙 2-1: 모든 TOFU 글에 "장면(scene)" 최소 1개를 포함한다.**

장면 = 시간 + 장소 + 감각 디테일이 있는 구체적 상황.

```
❌ 추상적 설명:
"많은 러너들이 후반부에 페이스가 떨어지는 경험을 합니다."

✅ 장면:
"하프 뛰는데 15km까지는 괜찮았습니다. 
그런데 갑자기 다리가 안 나가기 시작합니다. 
페이스는 떨어지고, 머리도 멍해지고."
```

**규칙 2-2: 장면은 "나" 또는 "당신"이 등장해야 한다.**
- McQuillan & Conde(1996): 비소설은 소설보다 서사 이동이 약하다. 인물이 있어야 이동이 발생한다.
- "필자도 30km 지점에서~" 패턴 적극 활용. 또는 "당신이 15km 지점을 지나고 있습니다."

**규칙 2-3: 장면은 도입부에 배치한다. 설명은 장면 뒤에 온다.**

```
[장면 — 경험 묘사] → [문제 제기] → [과학적 설명] → [실천 방법]
```

이 구조는 저널리즘의 "delayed lede"(지연 도입)와 같습니다. Digital Content Next 연구에서 참가자의 75%가 서사 구조를 역피라미드보다 더 몰입도 높다고 평가했습니다.

## 3. 구체성의 법칙 (The Specificity Principle)

### 과학적 근거
- Paivio(1971) 이중 부호화 이론: **구체적 단어는 언어 + 시각 두 시스템을 동시에 활성화**한다. 추상적 단어는 언어 시스템만 활성화. fMRI로 확인됨.
- Ogilvy의 롤스로이스 광고(1958): "시속 60마일에서 가장 큰 소리는 전기 시계 소리"라는 구체적 카피 → 전년 대비 **매출 50% 증가**.
- Hopkins의 Bissell 캠페인: 구체적 reason-why 카피 → DM 5,000부에서 **구매율 20%**.

### 실행 규칙

**규칙 3-1: 모든 주장에 숫자를 붙인다.**

```
❌ "훈련하면 지방 산화 능력이 좋아집니다."
✅ "존2 강도로 주 3회, 8주간 훈련하면 지방 산화율이 약 30% 향상됩니다."
```

**규칙 3-2: 추상어를 감각어로 교체한다.**

| 추상어 | 감각어 |
|--------|--------|
| 페이스가 떨어졌다 | 다리가 안 나가기 시작한다 |
| 에너지가 부족해졌다 | km당 페이스가 30초씩 늘어난다 |
| 효과가 있었다 | 5K 기록이 28:47에서 24:12로 줄었다 |
| 쿠셔닝이 좋다 | 두꺼운 요가매트 위를 걷는 느낌 |

**규칙 3-2-bis: "매거진 톤 함정어"를 풀어쓴다 (Journal 모드 특수)**

매거진B / Long Black 같은 에디토리얼 톤을 흉내 내려다 가장 쉽게 빠지는 함정이 있다. 시적으로 보이지만 독자에게 안 와닿는 추상명사들. AI가 "잘 쓰는 척"으로 해석하는 어휘들이다. 다음은 합쳐서 한 글에 5개 이하로 쓴다 — 5개를 넘으면 절반은 풀어쓴다.

| 매거진 톤 함정어 | 풀어쓰기 |
|---------------|---------|
| 산술 / 산술의 영역 | 계산 / 숫자 / "800kcal가 모자란다" |
| 임계점 / 임계 영역 | 한계 / 경계 / "20% 아래로 떨어지는 순간" |
| 분배의 문제 | "어느 연료를 얼마나 쓰는가" |
| 잔량 곡선 | "남은 양" |
| 처리 용량의 상한 | "처리 한계" |
| 정밀하다 / 정교하다 | (대체로 삭제 — 숫자가 알아서 보여줌) |
| ~의 자리다 / ~의 영역이다 | "~에서 다룬다" / "여기까지가 ~인 부분" |
| ~인 셈이다 / ~인 것이다 | (그냥 단언으로 — "~다") |
| 메커니즘이 / 패러다임이 | "원리가" / "구조가" |

비유어도 같은 원칙이 적용된다. "엔진" "발전소" "주유" "탱크" "보일러" "고급 연료/보통 연료" "즉답형 연료" 같은 비유는 한 단락에 1개 이하, 한 글에 합쳐서 1~2개 이하. 비유가 많아지면 매거진 톤이 아니라 자기도취 톤이 된다.

> **테스트**: 글을 다 쓴 후, 본문에서 추상명사로 끝나는 문장(~산술이다, ~한계다, ~문제다, ~자리다, ~영역이다)을 모두 세어본다. **5개 이상이면 일부를 구체적 사실로 다시 쓴다.** Journal 모드에서는 §4-7 "AI 톤 금지선"을 같이 본다.

**규칙 3-3: "러닝 숫자 3종 세트"를 자주 사용한다.**
우리 타겟(30~40대 남성 러너)이 즉시 이해하는 숫자:
- 거리 (km) — "32km 지점"
- 페이스 (분:초/km) — "5:30 페이스"
- 시간 (기록) — "서브4", "3시간 47분"

## 4. 감정 각성의 설계 (Emotional Arousal Calibration)

### 과학적 근거
- Berger & Milkman(2012, *JMR*): NYT 기사 ~7,000편 분석. **고각성 감정(긍정이든 부정이든)이 공유를 촉진한다.** 경외(awe)는 공유 증가. 분노·불안도 공유 증가. 슬픔(저각성)은 공유 감소.
- 실용적 의미: 러닝 콘텐츠에서 공유를 만드는 감정은 "경외"(인체의 놀라운 능력)와 "생산적 불안"(이것을 모르면 부상 위험)이다.

### 실행 규칙

**규칙 4-1: 글의 감정 톤을 사전에 지정한다.**

| 감정 | 각성 수준 | 공유 효과 | 우리 블로그에서의 활용 |
|------|----------|----------|---------------------|
| 경외(awe) | 높음 | 강한 공유 | "몸이 42km를 달릴 수 있게 만든 적응의 과학" |
| 생산적 불안 | 높음 | 강한 공유 | "이 폼 하나가 무릎 부상을 결정합니다" |
| 흥미/호기심 | 중간 | 보통 공유 | "존2에서 실제로 일어나는 에너지 대사" |
| 슬픔/아쉬움 | 낮음 | 약한 공유 | ❌ 사용하지 않음 |

**규칙 4-2: 한 글에 감정 톤을 2개 이상 섞지 않는다.**
- One Message Rule과 연동: 메시지 1개, 감정 톤 1개.

## 5. 슬리퍼리 슬라이드 (Slippery Slide) — 문장 간 연결

### 근거
- Joseph Sugarman: "독자는 카피를 읽기 시작하면 끝까지 미끄러져 내려가야 한다. 마치 미끄럼틀을 타듯이."
- 실행 도구: **오픈 루프**(§1), **버킷 브리게이드**, **문장 리듬**

### 5-1. 버킷 브리게이드 (Bucket Brigade)

문단과 문단 사이에 짧은 연결 문장을 넣어 독자의 눈을 다음 블록으로 넘기는 기법.

**규칙:**
- **400자당 1개 이하.** 과하면 AI스러워집니다.
- H2 전환 직전에 배치하면 가장 효과적.
- 반드시 독립된 짧은 문장(1줄)으로. 긴 문장에 섞지 않습니다.

**한국어 패턴:**

| 용도 | 예시 |
|------|------|
| 다음 논점으로 전환 | "그런데 이게 전부가 아닙니다." |
| 반전 | "하지만 여기서 반전이 하나 있습니다." |
| 심화 | "숫자를 보면 더 명확합니다." |
| 실천 연결 | "이걸 알면 대응이 달라집니다." |
| 요약 후 전환 | "정리하면 이렇습니다. 그리고 여기서부터가 중요합니다." |

**금지:**
- "자, 그럼 이제~" — 발표자 톤.
- "다음으로 넘어가겠습니다" — 보고서 톤.
- "뿐만 아니라!" — 감탄사 나열.

### 5-2. 문장 리듬 (Sentence Rhythm)

**근거:**
- Gary Provost(1985, *100 Ways to Improve Your Writing*): 같은 길이의 문장이 5개 연속이면 단조롭다. 길고 짧은 문장을 섞으면 "음악"이 된다.
- American Press Institute: 8단어 이하 문장 → 이해도 100%. 43단어 이상 → 이해도 10%.
- 한국어 적용: 한국어는 단어 수보다 **어절 수**가 기준. 3~5어절(짧은), 6~10어절(중간), 11어절 이상(긴).

**규칙:**
- **3문장 연속 같은 길이 금지.** 긴-짧-중간 또는 짧-짧-긴으로 섞는다.
- **핵심 주장은 짧은 문장으로.** 근거는 길어도 된다.
- **문단은 모바일 3~4줄.** 6줄 이상이면 분리한다 (네이버 모바일 기준).
- **한 문장이 2줄을 넘기면 끊는다.** 모바일에서 3줄 문장은 벽처럼 보입니다.

```
❌ 단조로운 리듬:
"글리코겐은 약 2,000kcal이 저장됩니다. 풀마라톤은 약 2,950kcal을 소모합니다.
에너지 적자는 약 950kcal입니다. 이 적자를 지방 산화로 보충해야 합니다."

✅ 리듬이 있는 문장:
"체내 글리코겐 저장량은 약 2,000kcal. 풀마라톤 소모량은 약 2,950kcal.
단순 산술로 950kcal이 부족합니다.
이 적자분을 지방이 메워야 하는데, 문제는 지방 분해 속도가 
그만큼 빠르지 않다는 점입니다."
```

### 5-3. 패턴 인터럽트 (Pattern Interrupt)

**근거:**
- Sokolov(1963): 정위반사(orienting response) — 뇌가 예측한 패턴이 깨지면 "이게 뭐지?" 반사가 발동하여 주의력이 재점화된다.
- 정위반사는 빠르게 습관화됨 → 인터럽트 유형을 매번 바꿔야 한다.

**규칙:**
- 글 1편당 **1~2개**. 도입부에 1개(상식 뒤집기), 본론 중반에 1개(예상 밖 정보).
- 뒤집은 뒤 반드시 **근거를 즉시 제시한다.** 근거 없는 뒤집기 = 클릭베이트.

**구조:**
```
[상식/예측] → [뒤집기] → [근거(논문/데이터)] → [새로운 방향]
```

**한국어 패턴:**
- "대부분 ~라고 생각합니다. 그런데 데이터는 다른 이야기를 합니다."
- "직관적으로는 ~이 맞아 보입니다. 하지만 연구 결과는 반대입니다."
- "~이 답이라고 알려져 있습니다. 절반만 맞습니다."

## 6. 네이버 모바일 최적화 (Naver Mobile Formatting)

### 왜 이것이 흡입력의 일부인가
네이버 블로그 트래픽의 **70% 이상이 모바일**입니다. 한국 스마트폰 보급률은 94.8%. 30~40대는 거의 100%. 아무리 좋은 글이어도 모바일에서 읽기 불편하면 이탈합니다. 포맷팅은 흡입력의 물리적 기반입니다.

### 실행 규칙

**규칙 6-1: "3줄 텍스트 + 1 이미지" 리듬을 기본으로 한다.**
- 한국 상위노출 블로그의 공통 패턴.
- 텍스트 벽(wall of text)을 방지하고 자연스러운 스크롤 마일스톤을 만든다.
- 이미지가 없는 구간은 **인용블록(>)** 또는 **표**로 시각적 변주를 준다.

**규칙 6-2: 글당 이미지 6~13장.**
- 네이버 DIA+ 알고리즘이 이미지 수를 품질 신호로 평가.
- 직접 촬영 이미지 권장 (네이버가 이미지 출처 감지).
- 이미지 alt 텍스트에 타겟 키워드 포함.

**규칙 6-3: 문단 간 여백을 넉넉히.**
- 모바일에서 문단이 붙어 있으면 한 덩어리로 보임 → 스크롤 압박.
- H2 전후로 빈 줄 1개 이상.
- 핵심 문장은 독립 문단으로 분리하여 시각적 강조.

**규칙 6-4: 본문 1,500~2,500자 (Cluster), 2,500~3,500자 (Pillar).**
- 네이버 권장 최소 1,500자(한국어 기준).
- Medium 데이터: 최적 체류시간은 7분 읽기(~1,600단어). 한국어는 정보 밀도가 높으므로 1,500~2,500자가 이 범위에 해당.
- Chartbeat: 2,000단어까지 체류시간이 꾸준히 증가. 4,000단어 이상은 불확실.

## 7. 한국어 말투 규칙

### 7-1. 문체 선택 근거
- 경어체(~요/~습니다): 친밀감, 대화적 톤 → 개인 경험, 커뮤니티 콘텐츠
- 평어체(~다): 권위, 객관성 → 사실 정보, 과학 설명

우리 블로그는 **경어체(~입니다) 기조 + 짧은 문장에서 체언 종결**로 둘의 장점을 결합합니다.
"지적이지만 딱딱하지 않은 동료 러너"의 톤.

### 7-2. 종결어미 배분

| 종결어미 | 비율 | 용도 | 예시 |
|---------|------|------|------|
| ~입니다/~습니다 | 60~70% | 기본 서술 | "원인은 글리코겐 고갈입니다." |
| ~됩니다/~집니다 | 15~20% | 변화/결과 | "같은 페이스가 점점 힘들어집니다." |
| 명사형 종결 | 5~10% | 짧은 강조 | "단순 산술로 950kcal 부족." |
| 체언 종결 | 강조 시 | 핵심 문장 | "근육이 아니라 뇌의 문제." |

### 7-3. 금지 종결어미
- ~에요/~예요, ~죠, ~거든요, ~고요, ~잖아요 — 캐주얼 과잉
- ~하겠습니다, ~드리겠습니다 — 서비스업 톤
- ~인 것이다, ~인 셈이다 — AI 번역체
- ~하는 바입니다 — 관료 톤

### 7-4. 3문장 연속 같은 종결어미 금지
"~입니다. ~합니다. ~있습니다." 연속 ❌
"~입니다. 950kcal 부족. 지방이 이를 메워야 합니다." ✅

## 8. 인지 유창성의 법칙 (Processing Fluency)

### 과학적 근거
- Alter & Oppenheimer(2009): **쉽게 처리되는 정보는 더 진실하다고 느껴진다.** 발음하기 쉬운 주식 이름이 IPO 당일 더 높은 수익률을 기록.
- Schwarz et al.: 처리 유창성 → 긍정적 감정 → 신뢰 → 친숙함 인식.
- 반대 활용: Alter et al.(2007): 의도적 비유창성은 분석적 사고를 촉발. **기본은 유창하게, 핵심 전환점에서만 의도적 복잡성.**

### 실행 규칙

**규칙 8-1: 기본은 쉽게. 전환점에서만 어렵게.**
- 본문의 90%: 중학생이 읽어도 이해할 수 있는 수준.
- 전환점(패턴 인터럽트, 핵심 주장): 한 단계 복잡한 문장으로 주의력 강제 전환.

**규칙 8-2: 전문 용어는 등장 즉시 번역한다.**
```
❌ "미토콘드리아의 구연산 합성효소(CS) 활성이 높으면 TCA 회로 속도가 빨라집니다."

✅ "미토콘드리아 — 근육 세포 안에서 에너지를 만드는 곳 — 의 핵심 효소 활성이 높으면,
같은 산소로 더 많은 에너지를 만들 수 있습니다."
```

**규칙 8-3: 한 문장에 괄호 2개 이상 금지.**
- 괄호가 많으면 시각적 복잡성 증가 → 유창성 저하 → 신뢰 감소.

## 9. 한국 독자 심리 특수 규칙

### 9-1. "우리-나" 이중 구조 (We-Me Paradigm)

연세대 장대련 교수의 프레임워크: 한국 소비자는 집단 트렌드를 따르면서(We) 동시에 개인 취향을 표현(Me)합니다.

**적용:**
- 러닝크루 문화, 공유 경험을 언급하여 "We" 충족 → "러닝크루에서 자주 나오는 질문입니다"
- 개인화된 데이터/기록으로 "Me" 충족 → "내 페이스에서 어떤 연료를 쓰고 있는지"

### 9-2. 사회적 증거 (Social Proof) 강화

테네시 대학교 연구: 한국 소비자는 미국 소비자보다 **타인의 의견을 먼저 탐색**하는 경향이 강함.

**적용:**
- 댓글 수, 이웃 수, 공감 수를 자연스럽게 언급 가능
- "많은 러너들이 같은 경험을 합니다" — 보편성 확인
- 러닝 커뮤니티(런갤, 러닝크루)에서 실제로 논의되는 주제를 다룸

### 9-3. 경험 기반 신뢰 (E-E-A-T의 "Experience")

한국 블로그 문화에서는 자격증보다 **직접 경험 증거**가 더 강력한 신뢰 신호입니다.

**적용:**
- 자기 기록, 훈련 로그, 레이스 사진 언급
- "저도 같은 경험을 했습니다" 패턴
- 한계도 솔직히 인정 (Strategic Honesty / Blemish Effect)

## 12. 흡입력 체크리스트 (4중 체크의 4번째)

글 작성 완료 후, 기존 규제(§7-1) + AEO(§7-2) + 내부링크(§7-3) 체크에 이어서:

### 흡입력 체크 (8항목)

**구조 설계 (3항목):**
- [ ] 정보갭: 2~3개 존재. 모두 1~3문단 내에 닫힘
- [ ] 장면(scene): 도입부에 시간+장소+감각이 있는 구체적 상황 존재
- [ ] 감정 톤: 글 전체에 걸쳐 1가지 감정(경외/생산적 불안/호기심)이 일관됨

**문장 수준 (3항목):**
- [ ] 버킷 브리게이드: H2 전환점에 연결 문장 존재
- [ ] 패턴 인터럽트: 도입부 + 본론 중반에 각 1개, 근거 동반
- [ ] 문장 리듬: 3문장 연속 같은 길이/종결어미 없음

**포맷팅 (2항목):**
- [ ] 모바일 기준 텍스트 벽 없음 (6줄 이상 연속 텍스트 ❌)
- [ ] 종결어미 배분: ~입니다 계열 60~70%, 변주 30~40%

## 13. 글쓰기 워크플로우 (적용 순서)

### Phase A: 설계 (글 쓰기 전)
1. One Message 확인 → "이 글의 핵심 메시지 한 문장은?"
2. 감정 톤 지정 → 경외 / 생산적 불안 / 호기심 중 택 1
3. 정보갭 위치 지정 → 도입부, 본론 전환점, (선택) 결론 전
4. 장면(scene) 구상 → 어떤 러닝 상황에서 시작할 것인가

### Phase B: 초안
5. 장면으로 시작 → 정보갭 열기 → 본론 진행
6. H2 전환점마다 버킷 브리게이드 삽입
7. 본론 중반에 패턴 인터럽트 1개 배치
8. 모든 주장에 숫자 붙이기 (구체성)

### Phase C: 검수
9. 4중 체크리스트 실행 (규제 → AEO → 내부링크 → 흡입력)
10. 문장 리듬 점검: 3문장 연속 같은 길이? 같은 종결어미?
11. 모바일 미리보기: 6줄 이상 텍스트 벽? 이미지 간격?
12. 소리 내어 읽기: 부자연스러운 곳 수정
