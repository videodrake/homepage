# 활성 시리즈 가이드

> 현재 작업 중인 시리즈의 톤 정의. Claude가 글을 쓸 때 이미지 프롬프트 설계 단계에서 참조.
> 새 시리즈 시작 시 이 문서에 항목 추가. 시작된 시리즈는 끝까지 수정 금지.
> v1 (2026-05-12).

---

## 1. 이 문서를 왜 보는가

자리 2(Codex)가 이미지를 생성할 때, `series_blocks/<시리즈ID>.yaml`에 정의된 4줄 고정 블록을 프롬프트 prefix로 자동 주입한다.

이게 의미하는 바: **같은 시리즈 안의 모든 이미지는 자동으로 같은 톤으로 묶인다.** 색감·모델·조명·스타일이 한 묶음.

따라서 Claude가 글을 쓸 때, **각 이미지의 자연어 프롬프트에 시리즈 톤 키워드를 중복 작성할 필요가 없다.** 오히려 중복하면:

- 프롬프트가 불필요하게 길어짐
- 시리즈 톤을 글마다 미세하게 다르게 적으면 톤이 어긋남
- 시리즈 톤 변경 시 글마다 수정 부담

올바른 접근: **자연어 프롬프트는 그 이미지의 고유한 내용만 다루고, 톤은 시리즈 블록에 위임한다.**

## 2. 시리즈별 톤 정의 — 현재 활성 시리즈

### 2-1. Journal №01 — 30km 페이스 유지 시리즈

**시리즈 ID**: `journal-01`
**적용 글**: `journal-01-a.md`, `journal-01-b.md`

#### 분위기 사진 / 인물 장면 (photo 카테고리)

| 키 | 값 |
|---|---|
| 색감 | cool blue-grey color grade with muted teal shadows, desaturated highlights |
| 모델 | Korean male runner in his late 30s, lean build, contemplative expression |
| 조명 | early dawn, slight mist, cool morning light just before sunrise |
| 스타일 | editorial magazine aesthetic, Magazine B style, no text overlay |

**감정 톤**: quiet intensity (조용한 강도), contemplative (관조적)
**의도**: 30km 표지판을 지나는 순간의 정적. 무너지기 직전, 또는 무너지지 않고 지나가는 시간.

#### 데이터 시각화 / 다이어그램 / 인포그래픽 (graphic 카테고리)

| 키 | 값 |
|---|---|
| 배경 | off-white background (#FAFAF7) |
| 메인 | deep navy (#1A2B3C) primary |
| 액센트 | warm orange (#E8743C) accent |
| 폰트 | Pretendard for Korean labels, rendered correctly |
| 스타일 | flat clean editorial design, no 3D effects |

**디자인 기조**: NYT graphics / FT Visual 결. 정확하고 정제됨. 화려한 시각 효과 없음.

#### 자연어 프롬프트 작성 시 주의

위 시리즈 블록은 자리 2가 자동 주입한다. **본인의 자연어 프롬프트에는 다음을 적지 않는다**:

- 색감 키워드 ("cool blue-grey", "desaturated", "muted teal")
- 모델 일반 설명 ("Korean male runner", "late 30s")
- 조명 일반 설명 ("early dawn", "morning light")
- 스타일 일반 키워드 ("editorial", "Magazine B style")

**본인의 프롬프트에는 다음만 적는다**:

- 이미지의 고유한 내용 (장소, 행동, 구도, 표지판, 차트 데이터 등)
- 비율 (예: "21:9 cinematic aspect ratio")
- 그 이미지에만 적용되는 특수 요구 (예: "30km marker visible on right third")

좋은 프롬프트 예시 (시리즈 블록은 자리 2가 주입):

```
> A male Korean runner passing a '30km' course marker on
> an empty urban marathon route. Composition: low-angle shot
> from behind, runner's silhouette against the soft grey horizon,
> the '30km' sign in sharp focus on the right third of the frame.
> Wardrobe: black running shorts, deep navy technical shirt,
> white running shoes, no race bib visible.
> 21:9 cinematic aspect ratio.
```

→ 자리 2가 자동 주입 후 GPT Image 2가 받는 최종:

```
[Series style guide: cool blue-grey color grade with muted teal shadows /
Korean male runner in his late 30s, lean build, contemplative expression /
early dawn, slight mist, cool morning light just before sunrise /
editorial magazine aesthetic, Magazine B style, no text overlay]

A male Korean runner passing a '30km' course marker on
an empty urban marathon route. ...
```

나쁜 프롬프트 예시 (시리즈 블록 키워드 중복):

```
> A cinematic editorial photograph of a male Korean runner
> in his late 30s, lean build, passing a '30km' course marker
> on an empty urban marathon route at early dawn. Setting: 5 AM,
> light mist hanging over the asphalt, the road still wet from
> overnight dew, cool morning light just before sunrise. (...)
> Color grade: cool blue-grey base with muted teal shadows,
> desaturated highlights. (...) Style: editorial magazine aesthetic
> similar to Magazine B (...).
```

이 프롬프트는 시리즈 블록 키워드를 거의 그대로 다 반복했다. 자리 2가 prefix를 또 붙이면 키워드가 두 번 등장한다. GPT Image 2가 혼동하지는 않지만, 프롬프트가 길어져 정작 고유 내용("30km marker", "low-angle shot")이 묻힌다.

본인의 프롬프트에는 다음만 적는다:

## 3. 새 시리즈 추가 절차

새 Journal 시리즈를 시작할 때:

### 3-1. 시리즈 톤 결정

다음 4가지를 결정:

1. **시리즈의 감정 톤** — 이 시리즈가 독자에게 주고 싶은 감정 한 단어
2. **photo 카테고리 4줄** — 색감 / 모델 / 조명 / 스타일
3. **graphic 카테고리 5줄** — 배경 / 메인 / 액센트 / 폰트 / 스타일
4. **종류 키워드 매핑** — "분위기 사진", "다이어그램" 등 종류 명칭

### 3-2. 두 곳에 동기화 기록

| 파일 | 형식 |
|---|---|
| `series_blocks/journal-NN.yaml` | YAML, 자리 2가 자동 읽음 |
| 이 문서의 §2 | 자연어, Claude가 글 쓸 때 참조 |

두 파일은 같은 정보를 다른 형식으로 담는다. **둘 중 하나만 수정하면 시리즈 톤이 어긋난다.** 항상 둘 다 동기화.

### 3-3. 첫 글 작성 후 검증

1. 시리즈의 첫 글(예: `journal-NN-a.md`)을 작성
2. 자리 2 Skill로 이미지 생성
3. 결과 이미지 검토. 톤이 의도와 맞는지 확인.
4. 톤이 어긋나면:
   - 시리즈 블록 YAML 미세 조정
   - 이 문서 §2 동기화
   - `assets/journal-NN-a/` 폴더 삭제 후 재생성
5. 톤이 맞으면 그 정의를 시리즈 끝까지 유지.

### 3-4. 시작 후 변경 금지

시리즈의 두 번째 글부터는 시리즈 블록을 변경하지 않는다.

변경이 불가피하면 시리즈 전체 이미지 재생성. 본문은 유지, `assets/journal-NN-*/` 폴더 모두 삭제 후 자리 2 Skill 재실행.

## 4. 글 쓸 때 적용 흐름

### 4-1. 새 글 시작 전

1. 이 문서에서 작업 대상 시리즈의 §2 항목 확인
2. 그 시리즈의 감정 톤·디자인 기조를 머리에 둠

### 4-2. 이미지 명세 작성 시

1. 각 IMG-N의 자연어 프롬프트 작성
2. 시리즈 블록에 이미 포함된 키워드는 **명시적으로 제외**
3. 프롬프트에 그 이미지만의 고유 내용만 작성

### 4-3. 작성 완료 후

자가 검증 도구는 시리즈 블록 적용 여부를 확인하지 않는다 (자리 2 책임).

다만 다음 인지:
- 시리즈 블록 키워드가 자연어 프롬프트에 중복되면, 결과 이미지가 의도와 미묘하게 어긋날 수 있음
- 시리즈 블록을 명시적으로 제외하고 작성하면 결과가 더 예측 가능

## 5. 자주 발생하는 혼동

**Q: 시리즈 블록과 다른 톤의 이미지를 한 글 안에 넣고 싶다 (예: "이 이미지만 따뜻한 색감")**

A: 그 글이 시리즈 일관성을 깨뜨릴 가치가 있는지 다시 검토. 가치가 있다면 시리즈 블록을 일반화 (예: "cool color grade" → "editorial color grade"). 일반화로 해결 안 되면 그 이미지는 다른 채널(인스타 카루셀 등)에서 다루는 게 시리즈 일관성 유지에 좋음.

**Q: 같은 시리즈 안에서 IMG-1은 새벽, IMG-5는 저녁 풍경을 다루고 싶다 (조명이 시리즈 블록과 충돌)**

A: 시리즈 블록의 "early dawn" 같은 시간 지정이 너무 좁다는 신호. 다음 시리즈에서는 "natural lighting"처럼 더 일반화. 현재 시리즈에서는 IMG-5의 자연어 프롬프트에 "late afternoon"을 명시. GPT Image 2는 본문 프롬프트를 prefix보다 우선시하므로, 본문에 명시한 조명이 반영된다.

**Q: 시리즈 블록을 무시하고 완전 다른 톤으로 가고 싶다**

A: 그 글은 그 시리즈에 속하지 않는다는 신호. 별도 시리즈 ID로 분류하거나, 단발성 글로 처리.
