# 온로드 러닝 노트 운영 기준

## 목적

러너가 검색하는 실제 질문으로 유입을 만들고, 글에서 얻은 신뢰가 제품 기준 확인과 구매 검토로 이어지게 합니다.

`검색 질문 → 근거 중심 글 → 관련 글 탐색 → 지구력 관리 루틴 → 상품 페이지`

## 글 한 편의 기본 구조

새 글은 `content/templates/journal-post-template.md`를 복사해 시작합니다.

1. 검색자가 겪는 구체적인 장면
2. 핵심 답변 요약
3. 원리와 근거
4. 실제 적용 기준
5. 자주 묻는 질문
6. 일반 정보 면책 문구와 출처
7. 제품 기능성과 분리된 온로드 루틴 안내

## 제목 원칙

- 한 글에 검색 질문 하나를 답합니다.
- 제목 앞부분에 핵심 검색어를 둡니다.
- 과장된 결과나 보장을 약속하지 않습니다.

예시:

- `마라톤 30km 이후 페이스가 떨어지는 이유`
- `마라톤 테이퍼링, 마지막 2주에 거리를 얼마나 줄일까`
- `여름 러닝 심박수가 높아지는 이유와 페이스 조절 기준`

## 최소 발행 빈도

초기 8주는 주 1편을 권장합니다. 새 카테고리를 넓히기보다 기존 글의 후속 질문을 먼저 발행해 주제 묶음을 만듭니다.

## 전환 원칙

- 본문에서 제품을 억지로 반복 노출하지 않습니다.
- 글 마지막에 제품의 역할, 기능성 근거, 하루 1정 루틴을 한 번 명확히 제시합니다.
- 일반 러닝 정보가 제품의 기능성이나 개인의 운동 성과를 뜻하지 않는다는 문구를 유지합니다.

## 발행 체크리스트

- 제목과 H1이 검색 질문을 명확히 답하는가
- 카테고리가 기존 다섯 개 중 하나인가
- 대표 이미지와 모든 이미지에 설명형 대체 텍스트가 있는가
- 출처와 일반 정보 면책 문구가 있는가
- 금지 표현이 없는가
- 상품 링크가 `/product/detail.html?product_no=11`로 연결되는가
- 모바일에서 표와 이미지가 가로로 넘치지 않는가
- 생성 후 `skin9/sitemap.xml`에 URL이 포함됐는가
