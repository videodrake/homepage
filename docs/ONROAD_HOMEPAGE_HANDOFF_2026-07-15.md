## 3. 사용자가 확정한 홈페이지 방향

### 디자인

- 밝고 역동적인 러닝 브랜드 톤을 유지한다.
- 기본 배경은 흰색·아주 밝은 회색이며, 코발트 블루·네이비·오렌지는 강조색으로 쓴다.
- 과거 시안처럼 화면 대부분을 네이비로 채워 전체가 어두워지게 만들지 않는다.
- 첫 화면에서 러너의 상황, 제품, 가격·혜택, 구매 버튼이 바로 보여야 한다.
- 모바일뿐 아니라 모든 너비에서 자연스럽게 반응해야 한다. 특정 화면만 맞춘 고정 줄바꿈을 반복하지 않는다.
- 제목은 `clamp()`와 `word-break: keep-all`을 기본으로 하고, 의미상 꼭 필요한 줄바꿈만 HTML에 둔다.
- 최소 확인 너비: 320, 360, 390, 430, 768, 1024, 1280, 1440px. 가능하면 1920px도 확인한다.

### 브랜드와 고객

- 첫 시장은 러닝이다.
- 핵심 고객은 일상적으로 달리는 생활 러너와, 대회 참가까지 생각하며 본격적으로 시작하려는 러너다.
- 운동을 막 시작한 완전 초보와 기록 경쟁 중심 엘리트는 **제외가 아니라 우선순위 보류**다.
- 러닝 이후에는 계절·관심도에 따라 등산, 자전거 등 생활체육으로 확장할 수 있다.
- 핵심 방향: `이제 지구력도 관리받는 시대.`
- 현재 사이트 적용 기준 문구: `지구력 관리, 이제 일상에서부터.`
- 제품은 달리는 중 즉시 먹는 보충제가 아니라, 달리는 생활 속에서 평소 꾸준히 챙기는 관리형 루틴으로 설명한다.

### 제품·오퍼 확정값

| 항목 | 기준 |
|---|---|
| 제품 | 온로드 지구력코어 |
| Cafe24 상품번호 | `11` |
| 가격 | 1박스 38,900원 |
| 규격 | 60정 |
| 섭취 | 하루 1정, 약 60일분 |
| 첫 구매 혜택 | 3,000원 쿠폰 |
| 쿠폰 적용 예시 | 35,900원 |
| 기본 배송 | 1박스부터 무료배송 |
| 2박스 가격 | 미확정 — 임의로 만들지 않음 |
| 제주·도서산간 | 추가배송비 약 1,000원 검토 중, 아직 확정 아님 |

쿠폰의 최소 주문금액, 유효기간, 중복사용 조건은 아직 관리자에서 최종 확정해야 한다. 페이지에 확정값처럼 새 조건을 만들지 않는다.

### 제품 근거

- 옥타코사놀 40mg 함유
- 표시 가능한 기능성: `지구력 증진에 도움을 줄 수 있음`
- 비타민B1·B2·B6·나이아신·판토텐산 기능성 원료
- 타우린·비타민C·아르기닌은 부원료로 함께 담았다는 수준만 표현
- 옥타코사놀 원료 원산지: 미국산
- 제조원: `(주)상상바이오`
- 제조·GMP·HACCP 관련 서류는 사용자에게 있으며, 사이트에서 인증 주체와 문구를 확정하기 전에 증빙을 받아 확인한다.

## 4. 카피와 표시광고 기준

### 사용할 수 있는 방향

- 운동도, 일상도 결국 나만의 페이스가 필요하니까
- 하루 1알로 챙기는 지구력 관리 루틴
- 러닝을 삶에 넣은 사람이 평소 매일 챙기는 관리형 건강기능식품
- 옥타코사놀 40mg 함유
- 지구력 증진에 도움을 줄 수 있음

### 사용하지 않을 표현

- 피로회복, 체력 개선 보장, 컨디션 회복 보장
- 먹으면 바로 힘이 남, 하루 종일 지치지 않음
- 운동 능력·기록·성과 향상을 보장하는 표현
- 질병 예방·치료 표현
- 실제 근거 없이 `아기유니콘 제조업체`, `최대 함량`, `최대 용량` 등을 단정하는 표현

마케팅 내부 아이디어에서는 과감한 문구를 검토했지만, 홈페이지 공개 문구는 최종 단계에서 표시광고 기준과 제품 표시사항을 다시 대조한다.

상품 상세에서는 Cafe24 관리자에 등록하고 심의받은 상세 콘텐츠를 그대로 사용해야 한다. `skin9/product/detail.html`의 `{$product_detail}` 연결을 삭제하거나 자체 제작 상세로 대체하지 않는다.

Cafe24의 아래 항목도 보존한다.

- `{$...}` 변수
- `module="..."` 모듈 구조
- `<!--@layout(...)-->`, `<!--@css(...)-->`, `<!--@js(...)-->`, `<!--@import(...)-->`
- 옵션, 수량, 총액, 바로구매, 장바구니, 찜, 품절, 네이버페이, 리뷰, Q&A 모듈
- `order/`, `member/`, `myshop/`, `css/module/`, `js/module/`의 플랫폼 기능

## 6. Journal·블로그 방향

홈페이지 안의 Journal은 이미지 중심 매거진보다 **질문 중심 검색 자산**으로 운영한다.

- 실제 러너가 검색하는 한 가지 질문을 제목과 H1 앞부분에 둔다.
- 첫 120자 안에서 조건을 포함한 직접 답변을 준다.
- 이미지보다 질문, 결론, 적용 기준이 먼저 보이게 한다.
- AEO/IEO 구조: 직접 답변 → 판단 기준 → 적용 순서 → FAQ → 출처 → 관련 글.
- 제품을 억지로 반복하지 않고 글 마지막에서 하루 1정 지구력 관리 루틴으로 한 번 연결한다.
- 성분 직접 홍보 글보다 30km 벽, 에너지젤 섭취, 테이퍼링, 대회 전날, 여름 심박·페이스처럼 실제 문제 검색을 우선한다.
- 세부 운영 기준은 `docs/ONROAD_JOURNAL_OPERATIONS.md`와 `content/CONTENT_STATE.md`를 따른다.

현재 6개 AEO 개편 글은 `published_md_ready` 상태이며 사용자 승인 후 배포 대기다. 새 글을 늘리기보다 이 6개의 렌더링·링크·모바일 표·출처를 먼저 검수한다.

## 7. 다음 홈페이지 세션의 권장 순서

1. 이 문서와 `docs/ONROAD_JOURNAL_OPERATIONS.md`를 읽는다.
2. `git status --short`, `git diff --stat`, 현재 브랜치를 확인한다.
3. 로컬에서 홈·상품·Journal을 렌더링한다. Cafe24 변수 때문에 정적 미리보기에서 깨지는 부분은 실제 skin9 미리보기와 구분한다.
4. 홈의 밝은 톤, 모든 너비의 줄바꿈·가로 넘침, 헤더·푸터, CTA를 확인한다.
5. 상품 페이지에서 구매 모듈과 `{$product_detail}`을 보존한 채 정보 위계와 전환 흐름을 점검한다.
6. Journal 6개 개편본과 질문 중심 허브를 검수한다.
7. 사용자에게 데스크톱·모바일 렌더링을 보여 승인받는다.
8. 승인 전에는 Cafe24에 배포하지 않는다.
9. 승인 후 `deploy-cafe24-skin9.yml`만 사용해 `/skin9`에 배포한다.
10. 배포 후 skin9 미리보기에서 확인하고, 대표 디자인 전환은 사용자가 별도로 결정한다.

### 로컬 명령

```powershell
npm install
npm run journal:preview
npm run journal:validate -- content/published/journal-01-a.md --type published --slug journal-01-a
```

필요하면 저장소의 `tools/audit-journal-preview.mjs`와 Playwright를 사용한다. 로컬 검수 없이 배포 결과로 디자인을 확인하는 흐름으로 돌아가지 않는다.

## 8. 배포 안전 규칙

- 배포 워크플로: `.github/workflows/deploy-cafe24-skin9.yml`
- 소스: `skin9/`
- 원격 대상: `/skin9/`
- 워크플로는 배포 전 기존 `/skin9`를 백업하고, rollback artifact를 14일 보존한다.
- `/base`와 `/skin8`은 건드리지 않는다.
- 구형 `.github/workflows/deploy-cafe24-skin8.yml`은 `skin9/`를 `/skin8`에 덮어쓰는 워크플로이므로 홈페이지 후속 작업에서 실행하지 않는다.
- `deploy-cafe24.yml`은 기존 `/base` 배포용이다. 대표 디자인을 교체하라는 명시적 승인 없이는 실행하지 않는다.
- 코드 배포와 Cafe24 관리자 설정은 별개다. 가격, 쿠폰, 배송비, 상품명은 관리자에서 맞춰야 한다.

## 9. 남은 결정과 필요한 자료

- 첫 구매 3,000원 쿠폰: 유효기간, 최소 주문금액, 중복 사용 여부
- 제주·도서산간 추가배송비 최종 금액
- 2박스 구성과 가격
- 고해상도 제품 정면·측면·후면 사진
- 제품 표시사항 원본과 품목제조신고번호
- 제조원 GMP/HACCP 증빙과 사이트 표시 문구
- 네이버·쿠팡·와디즈 후기 원문 및 홈페이지 재사용 범위
- 리뷰 제공 시 이름·사진·플랫폼 표시와 개인정보 사용 범위

근거가 오기 전에는 가짜 후기, 임의 별점, 가짜 재고 수량, 방문자 수, 카운트다운을 만들지 않는다.

## 10. 마케팅 작업 마감 메모

이번 마케팅 세션은 인스타 카드뉴스 실험 단계에서 종료했다. 홈페이지의 기준을 바꾸는 확정 디자인 자산은 아니다.

- 에너지젤 비교 카드의 마지막 방향: 인스타 4:5, 에너지젤은 회색으로 후퇴, 지구력코어는 저채도 블루로 강조.
- 비교 항목 아이디어: 제품 분류 / 기능성 / 함량 / 비용.
- 비교 비용·`최대용량` 문구는 출처와 법적 표현을 다시 검토하기 전 홈페이지에 옮기지 않는다.
- 앞으로 마케팅을 재개할 때는 첫 장 후킹 → 중간 가치 입증·반박 제거 → 마지막 구매 오퍼의 반복 가능한 공식을 사용한다.

홈페이지 세션에서는 위 카드뉴스 제작을 이어가기보다 홈·상품·Journal의 완성도와 실제 구매 동선을 우선한다.
