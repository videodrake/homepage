조사일: 2026-10-11. 대상: Cafe24의 단일 제품 스토어 `onroad.zenera.kr`. 기존 화이트·제품 중심 방향과 승인된 제품 사진·상세 이미지를 유지한다.

브랜드 페이지는 브라우저로 실제 화면과 정보 구조를 확인했다. 타사 제품의 효능·후기·인증·무료 배송·구독·할인 문구를 온로드에 옮기지 않는다. 자동 슬라이드와 복잡한 상품 선택은 단일 제품이라는 조건에 맞지 않아 채택하지 않는다.

## UX 근거

- [Baymard: 추가 제품 사진에는 썸네일 사용](https://baymard.com/research-articles/always-use-thumbnails-additional-images): 점 표시만 있는 갤러리는 사진 내용을 예측하거나 원하는 사진을 찾기 어렵다. 네이티브 사진 기능을 보존하고 선택 상태와 키보드 접근성을 보완한다.
- [Baymard: Product Page UX](https://baymard.com/research-articles/current-state-ecommerce-product-page-ux): 배송비 등 구매 비용을 확인하기 위해 장바구니로 이동해야 하는 마찰을 줄인다. 홈 가격·배송 표시는 공개 상품 페이지에서 읽으며, 실패 시 확인 링크를 유지한다.
- [W3C: WCAG 2.2 Target Size](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html): 터치 목표 사이즈와 간격을 고려한다. 주요 조작부는 44px 이상을 목표로 한다. 이는 WCAG 전체 준수를 주장하는 것이 아니다.
- [W3C: WCAG 2.2](https://www.w3.org/TR/WCAG22/): 고정 헤더·하단 영역이 포커스와 읽는 내용을 가리지 않도록 여백, 앵커 오프셋, 모션 감소 환경을 고려한다.

## 현재 사이트에서 개선할 점

1. 홈에 가격과 배송 정보가 없고 성분 정보가 다른 페이지에 흩어져 있다.
2. 구매 판단을 도울 내용이 적어 홈의 정보 진행이 짧게 끝난다.
3. 긴 상세 이미지를 읽다가 수량·구매 영역으로 돌아가기 어렵다.
4. 상품 테이블의 요약 설명·배송 방식이 중복된다.
5. 모바일 메뉴와 이미지 선택의 터치 영역·포커스 표시를 보완할 수 있다.

## 설계

홈: 제품과 구매 정보 → 핵심 수치 → 성분별 함량 → 섭취·포장 → FAQ → 제품 구매. 화이트 바탕, 네이비 텍스트, 패키지의 오렌지 강조, 선과 타이포 중심. 불필요한 카드 반복·과장 문구·가짜 후기·자동 재생을 넣지 않는다.

상품: Cafe24의 실제 가격·수량·주문 기능 유지. 원료·주의사항을 접어 읽을 수 있게 하고, 현재 상세 구간 표시와 구매 영역 복귀를 제공한다. 하단 구매 영역은 원래 구매 버튼을 지났을 때만 나타나며 주문을 자동 실행하지 않는다.

가격·배송 관리자 설정을 바꾸지 않는다. 홈 가격은 공개 상품 11에서 가져오고 받지 못하면 숫자를 추정하지 않는다. 상품 합계는 배송비 포함 결제 총액으로 표현하지 않는다.
