# Homepage 인수인계 (2026-09-20)

정본은 공개 저장소 `videodrake/homepage`의 `main`이다. 이 문서는 2026-09-20 확인한 코드 커밋 `ec3172d90fa132a6c289354281c672c97a03f269`을 기준으로 한다. 최신 변경은 모바일 상품 화면과 기존 문의 영역을 수정한 PR #66이다. 이 코드가 현재 운영 사이트에 배포됐는지는 별도로 확인해야 한다.

## 프로젝트 구성

- `skin9/`: 신규 Cafe24 스킨의 홈, 상품 상세, Journal 화면.
- `cafe24/`: Cafe24 템플릿과 기존 운영 코드. 플랫폼 변수와 모듈 지시문을 보존한다.
- `project/`: 화면 프로토타입과 디자인 참고 자료.
- `content/`, `tools/`: Journal 콘텐츠와 생성·검증 도구.
- `docs/`: [기존 홈페이지 인수인계](ONROAD_HOMEPAGE_HANDOFF_2026-07-15.md)와 [Journal 운영 절차](ONROAD_JOURNAL_OPERATIONS.md).

`skin9/` 변경을 기존 스킨에 자동 반영하지 않는다. Cafe24 템플릿의 `{$...}` 변수, `module="..."` 구조, `<!--@...-->` 지시문은 유지한다.

## 새 환경에서 확인할 순서

1. 최신 `main`을 받고 `npm ci`로 도구 의존성을 설치한다.
2. 콘텐츠를 바꿨다면 `npm run journal:validate`와 `npm run journal:preview`를 실행한다. 배포용 출력을 만드는 `journal:stage`는 결과를 검토한 뒤 사용한다.
3. 화면 수정은 데스크톱과 모바일에서 렌더링하고 상품 선택·구매 동선을 확인한다. 로컬 정적 미리보기에서는 Cafe24 변수가 치환되지 않으므로 실제 스킨 미리보기와 구분한다.
4. 현재 운영 사이트의 배포 버전, 워크플로 실행 결과, 필요한 승인 상태를 확인한다. 코드 커밋만으로 배포 완료를 판단하지 않는다.

다음 작업은 최신 브랜드·상품 문구를 확인하고, 모바일 상품 화면 및 Journal의 실제 렌더링을 검수한 뒤 배포 범위를 결정하는 것이다.
